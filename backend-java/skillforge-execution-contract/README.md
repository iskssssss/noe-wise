# 执行传输契约

本模块由机构宿主、Workflow 脚本调用方和独立沙箱共同消费，维护执行控制 DTO、类型化文件清单、显式业务结果及执行容量常量。它不依赖宿主业务或 Runtime 状态机，不拥有授权、调用预算、账单、任务恢复或成果发布状态。

传输采用 `ExecutionManifest` 与流式 ZIP；文件正文不进入控制 JSON。`ExecutionInputSource` 是宿主本地的懒读取契约，不能作为网络载荷序列化。`PublicResults` 仅允许业务文字和标量表格，执行状态、工具标题及成果引用由可信服务构造。详细职责与失败语义见[沙箱与产物交付设计](../../docs/02-架构与设计/12-代码执行沙箱与产物交付.md#41-执行传输与业务结果)。

发布与消费方编译由各自模块构建验证；变更契约时直接同步全部调用方，不保留旧 JSON 内嵌文件入口或双格式读取。
