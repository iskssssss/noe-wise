# 性能

按任务读取[性能工程](references/performance-engineering.md)：先确定用户可观察终点与可比工作量，再建立或复用基线，按测得的成本优化并核对受影响行为。

纯调查在热点、证据和限制清楚时结束；实施优化比较同输入 before/after；新增或收紧回归预算时才增加负向对照。报告原始样本、统计口径和排除项，组件耗时不代替端到端结果，结构调整不自证效率改善。阈值归需求或已有基准，不新增所有任务必跑的性能门禁。
