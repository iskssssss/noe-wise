# 基础执行

首次任务读[开发流程](references/development-workflow.md)；恢复先读已有状态摘要，按其[启动顺序](references/development-workflow.md#启动顺序)核对差量和活动执行。已掌握且未变化的规则不重读，专题链接只用于定位。

## 按任务加载

按当前动作选入口，不按一条固定流水线遍历技能。专题不会增加提交、通信、部署或数据操作授权。

| 当前任务 | 入口 |
|---|---|
| 设计或实现代码 | [工程](../nw-engineering/SKILL.md) |
| 页面布局、反馈、弹层或交互行为 | [UI 与交互](../nw-ui-ux/SKILL.md) |
| 模型可见的工具、提示词或上下文 | [模型使用体验](../nw-agent-experience/SKILL.md) |
| 错误契约、降级、重试或恢复设计 | [错误处理](../nw-error-handling/SKILL.md) |
| 数据字段、SQL、MyBatis 或迁移 | [数据库](../nw-database/SKILL.md) |
| 选择测试、复用证据或核验交付 | [验证](../nw-verification/SKILL.md) |
| 评审差量或处理评审意见 | [代码评审](../nw-code-review/SKILL.md) |
| 定位失败或异常结果 | [排障](../nw-debugging/SKILL.md) |
| 测试资源、子进程装配或偶发失败 | [测试可靠性](../nw-test-reliability/SKILL.md) |
| 性能调查、优化或已有预算回归 | [性能](../nw-performance/SKILL.md) |
| 明确简化/清理，或旧实现阻断交付 | [简化](../nw-simplification/SKILL.md) |
| 文档、长期决策或复盘 | [文档](../nw-docs/SKILL.md) |
| 已授权委派、跨会话接替或资源交接 | [协作](../nw-coordination/SKILL.md) |
