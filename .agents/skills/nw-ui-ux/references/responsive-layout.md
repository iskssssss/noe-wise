# 响应式与输入适配

仅在宽度、内容溢出、面板布局或输入方式变化时读取。组件、反馈和验收沿用 [UI 技能](../SKILL.md)，不新增页面状态或设备支持承诺。

## 适用范围与观察点

两个后台按[桌面优先范围](../../../../docs/03-规范与术语/05-后台系统交互规范.md#1-事实源与适用范围)处理桌面窄窗口和缩放；独立会话端保留自身已有窄屏面板与触屏行为，不导入后台控件。验收尺寸来自任务约定及所属产品支持范围；未约定统一最小宽度时不发明全项目数值。

选择受影响布局的宽窗口、变换前后及必要的窄窗口观察点，不只检查设备预设名称。弹层打开、长标题、错误提示、缩放和面板展开都可能减少可用空间；需要手机体验时再核对触屏、软键盘、安全区及动态可用高度。

桌面优先不豁免文字缩放与内容重排，具体尺度见[视觉规范](../../../../docs/02-架构与设计/09-前端视觉与交互规范.md#31-可访问性尺度)。浏览器缩放和用户覆盖字距后，标签、错误与操作仍可读可达；二维布局例外只限确需二维关系的区域，不扩展到整页、表格外围的筛选和分页。

## 空间分配与信息保留

先调整可伸缩区域和换行，再考虑收起次要区域、截断或图标化。保留主要动作、当前对象、关键状态与失败原因；不能靠页面级 `overflow: hidden`、统一缩小字体或压缩点击区域掩盖冲突。

页标题和卡片标题优先自然换行，操作区必要时独占一行。长 ID、URL、无空格文本和代码使用所属换行或滚动方式；表格、编辑器与代码块可在自身容器横向滚动，不能带动整个页面意外横向滚动。表单保持标签与输入对应，滚动后关键动作仍可到达。

截断内容要有可操作的完整查看入口；桌面 Tooltip 可以补充短文本，但不能成为关键错误或操作说明的唯一来源。详情、展开或复制按内容用途选择，复制并不等于用户已经能阅读。错误、确认影响和无其他查看入口的关键信息保持完整。

## 图标、触屏与焦点

文字动作缩成图标前确认语义可识别且有可访问名称；桌面必要时提供 Tooltip，低频或容易混淆的动作保留文字或移入有文字的菜单。关键操作不能只在鼠标 hover 时出现。

用实际输入能力判断 hover，例如 `@media (hover: hover)`，不以窗口宽度推断是否有鼠标。触摸后不残留仅用于悬浮的高亮，选中、按下和键盘焦点仍各自保留。触屏点击应直接执行动作，不以第一次点击只显示动作名提示；确需阅读的解释提供独立点击入口。

拖动排序、文件拖入或拖拽连接提供点击即可完成的替代，如上移/下移、选择文件或依次选择连接两端；同时保留适用的键盘操作。仅有键盘替代不足以满足[非拖动指针操作要求](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)；拖动本质必要或浏览器原生且未修改的能力按标准例外处理。

宽度改变或面板重排时尽量保留当前编辑值、光标、焦点与阅读位置，不通过重建整个表单实现切换。当前控件确实移除时将焦点移到可预测入口；移动端除明确的编辑动作外不自动弹出软键盘，键盘出现后输入与发送/保存仍可到达。

## 定向核对

针对改动检查关键动作可达、长内容可读、无意外裁切及焦点连续；涉及触屏才增加点击、hover 和软键盘场景。报告实际查看的尺寸、主题、输入方式与未验证范围，单个宽度通过不代表全部设备适配完成。
