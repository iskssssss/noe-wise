# 灵知 文档

普通编辑读取[写作规则](references/documentation-standards.md#3-写作规则)、[自检](references/documentation-standards.md#4-文档自检)和[链接](references/documentation-standards.md#8-链接与锚点)。范围与授权沿用已读[基础规则](../nw-workflow/references/development-workflow.md)。

| 条件 | 补读 |
|---|---|
| 新增、迁移事实或归属不明 | [事实归属](references/documentation-standards.md#1-分级体系每类事实只有一个家) |
| Runtime 主文档或长期决策/实施记录 | [Note 触发](references/notes-governance.md#4-note-触发与复用)，满足条件再读生命周期与追溯章节；记录目录按需创建，不要求历史 Note 存在 |
| 生成物、ADR 或篇幅问题 | 文档规范中对应的[生成](references/documentation-standards.md#5-生成式文件规则)、[ADR](references/documentation-standards.md#9-adr-状态与索引)或[篇幅](references/documentation-standards.md#6-文档质量与篇幅)章节 |
| 事故或返工复盘 | [复盘规范](references/postmortem.md) |
| 技能与流程规则变更 | [规则场景核对](../nw-verification/references/candidate-driven-delivery.md#规则场景核对) |
