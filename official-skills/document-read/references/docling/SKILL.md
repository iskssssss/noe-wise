# Docling 读取方法参考

本参考介绍文档转换的概念，不是另一个可激活的工具入口。实际执行仅使用根 Skill 的受管 read_document.py，输入字段、文件类型和模型范围见 [平台读取契约](../input-contract.md)。

Docling 将文档归一为正文、表格和结构。读取结果须区分转换状态、原件总范围、所选页范围与公开片段；不能把部分成功、缓存值或截断正文当成完整观察。扫描件 OCR 的准确率取决于原件，关键信息应核对。

结构化 PDF 使用固定本地布局、OCR、表格模型；native PDF 只读原生文本，不能推定布局和表格重建。Office 读取原生结构，不按打印页截取。平台不启用 VLM、远程服务、音视频或运行时模型下载。

其他参考仅解释结构、流水线与结果概念，不授予额外安装、联网、宿主路径或知识入库权限。
