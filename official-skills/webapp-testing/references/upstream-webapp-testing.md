# 浏览器检查的方法参考

采用先观察、再操作的方法；执行入口和允许动作以 [受管检查契约](check-contract.md) 为准。

先读真实挂载 HTML；不熟悉动态控件时先用空 steps 获取有限 DOM 摘要，再按实际控件编写选择器和状态断言。等待可观察的就绪元素或 DOM 状态，不用固定延时推定完成。选择器尽量稳定且唯一。

每个视口从初始状态完整检查关键交互和键盘操作，并核对浏览器运行错误、被阻断的网络请求和水平溢出。断言失败保留真实报告；截图通过 read_image 实际进入模型后才算视觉审阅。长页顶部截图不能证明整页通过。

平台使用受管离线 Chromium，不启动服务器，不安装依赖，不连接外站或个人浏览器，不执行任意验收代码。
