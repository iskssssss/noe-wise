# 演示文稿检查

先回读 `result.json` 的 `results[0].text` 中的检查报告 JSON 字符串，核对输入源页数、生成页数、每页 `source_index`、`part/parts`、表格行数与图表系列数。外层只含现有公共结果契约的 `results` 文本列表。`layout_budget: passed` 仅说明生成器保守布局检查通过，报告保留 `visual_review: required`；它不证明 PPTX 已完成视觉检查或客户端兼容验证。

文件结构检查应读取实际 PPTX 包：有可编辑文字形状、原生 `a:tbl` 表格、`c:chart` 图表引用及其嵌入 XLSX，图片为独立媒体，页面不是一张整页截图。检查 XML 中每段源文字完整保留、表格行按顺序覆盖、图表分类和数值与任务数据一致。生成成功和扩展名正确不能代替结构证据。

渲染所有页并查看实际预览，检查：

- 中文字体、标点和英文混排可读，没有缺字方框；替代字体造成重排时修正后重新渲染。
- 标题、副标题、正文和页码没有越界或相互遮挡，分页后完整保留原内容，续页次序明确。
- 双栏标题和正文对齐，空的一侧不重复已有正文；单项长段续页保留语义。
- 指标数值、说明和标签分别可读，示例值与真实任务事实明确区分。
- 表格重复表头，最后一行完整且不覆盖页码，单元格无裁切，所有数据行出现一次。
- 图表分类、系列、图例和数值符合源数据，嵌入工作簿和图表保持可编辑。所有数值非负的柱形图纵轴从 0 起，避免截断轴夸大差异；含负数的柱形图保留完整负值范围，折线图和饼图不套用柱形图基线规则。
- 图片比例与 `contain/cover` 意图相符，关键区域未被错误裁切，字幕不遮图。

模型只能在页图通过通用图片链路实际进入模型后报告已看图；下载链接和渲染成功日志不等于视觉输入。模型无法读取页图时保留视觉未验证状态，交由人工检查。

请求 PDF 时另外检查转换后的页数、中文字体与内容。PDF 正确不能证明 PPTX 在 Microsoft PowerPoint 和 LibreOffice 等所有客户端排版一致。

缺失图片、非法路径、未知字段、超长标题、无法分页的表格行或无效图表应明确失败；禁止静默跳过或改成截图交付。检查报告、预览与转换中间文件不是用户未要求的正文文件。
