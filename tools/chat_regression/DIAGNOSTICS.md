# 冻结执行的离线终态诊断

使用 `behavior_terminal_diagnostic.py` 从已冻结的 Product 单次试验提取终止事件、输出门禁拒绝、工具业务结果和委派顺序。该工具不登录、不执行模型、不重评原报告，也不自动把缺失最终答复归类为产品缺陷。

```powershell
python -X utf8 -B tools/chat_regression/behavior_terminal_diagnostic.py --root <冻结批次目录> --case <用例ID> --out <新私有目录>
```

输出 `diagnostic.json` 绑定计划、批次、原判定、执行证据和私有轨迹的 SHA-256。输入需已完成冻结且计划指纹与批次绑定一致；输出必须独立，不覆盖源报告。输出仅包含事件身份、顺序及限定的状态字段，不复制模型正文、推理、工具参数或输出拒绝反馈。

## 判读边界

- `SUCCEEDED` 是调用传输/执行状态；业务结果的 `success=false` 单独记为 failed，没有明确业务状态记 unknown。不能用传输成功证明文件已交付。
- 预算终止原因保留为事件事实；后续完成事件不能抹掉此前的截断。诊断器不裁定整批通过。
- WAIT 返回两个子任务结果不等于父任务已完成；最终答复仍需原有身份与时序断言。
- `INPUT_TOKEN_BUDGET_EXCEEDED` 可能来自“已用输入 + 下一次上下文预计输入”的前置检查，不要求已记账 token 先超过上限。
- 缺证据维持 unknown；缺陷分类和人工结论独立记录。业务失败不因诊断清楚而变绿。

## 定向回归场景

1. 输出契约：覆盖纯文本完成、合法文件完成、输出契约拒绝后修正，以及有依据的放弃；缺省值、空字符串变化和伪造资源 ID 应有负例。
2. 父任务完成：两个子结果已返回后，分别验证预算足够与不足的后续决策；不足时保留终止事实与已完成结果，不伪造汇总成功。
3. 委派幂等：确定性重复同一完整任务，核对身份复用；不同任务身份分离，不依赖模型随机重复派发。

每次验证绑定实际候选、配置和证据目录。单元测试、真实数据库、真实模型与跨进程恢复分别报告，未执行的场景保持未运行。
