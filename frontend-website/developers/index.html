开发者

选择服务入口和扩展方式。具体接口地址、鉴权与字段以目标环境的已发布契约为准。

接入路径

会话端与渠道
使用现有会话端时，先配置可访问的智能体；接入机构渠道或多人群时，补充用户身份映射、消息事件与响应投递。
自有应用与开放接口
在自有应用中提供服务时，准备应用凭据与用户身份，连接会话、事件和业务回调。接口范围以目标环境为准，完整开放平台仍在分阶段完善。
运行时 SDK
将智能体执行集成到自己的服务时，由宿主提供模型、存储、策略与能力适配，并验证等待恢复、取消和结果保存。
桌面原型原型
使用桌面原型前，配置模型并选择允许访问的本地目录。任务上下文会发送给所配置的云端模型，文件与命令在本地执行。

能力扩展

查看四类能力职责 ↗

通过技能包、工具、知识源和工作流扩展业务能力。模型提供方、连接器与渠道按接入职责装配；专业智能体委派单独授权。

接入前确认

  1. 明确用户目标、输入材料与交付要求。
  2. 确认机构范围、身份来源及资源授权。
  3. 配置模型、知识、工具和所需运行环境。
  4. 验证一次真实调用及其业务回执或成果。
  5. 检查等待、取消、失败和结果未知时的处理。
