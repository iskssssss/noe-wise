## 1. 安全与隔离

### 1.1 身份、动作和对象授权

平台账号、机构成员、渠道终端身份、机构 ServicePrincipal 和跨机构应用治理身份分别认证。平台主体不能通过请求中的 tenant_id 获得机构成员身份；菜单可见、资源共享、功能开通和套餐容量不能替代动作权限。分层见 [SaaS 基础底座](../02-架构与设计/19-SaaS基础底座设计.md#2-身份动作对象与商业授权分层)。

| 边界 | 已批准要求与当前依据 |
| :--- | :--- |
| 后台登录 | 平台与机构使用独立签名密钥及 issuer/audience。access JWT 引用权威设备会话，入口校验当前期限、撤销、账号启停、密码指纹和认证状态；有效签名不能代替当前安全会话校验 |
| 当前授权 | 从当前持久角色、已注册动作、组织范围和授权版本计算，不以 JWT 旧角色或账号单 role 字段授予权限。具体对象继续验证真实归属、所有权、部门范围与明确共享 |
| 刷新凭据 | 随机刷新凭据引用同一权威安全会话并以 CAS 轮换；原凭据已消费、会话撤销或竞争失败则拒绝签发，refresh 不是 JWT |
| MFA | 所有后台账号默认关闭，可自愿绑定；全员策略须显式发布。验证码和恢复码防重放，已启用账号的高风险写入要求最近五分钟证明；challenge/enrollment 会话不能访问普通管理能力，密码恢复不能绕过 MFA |
| 渠道身份 | 终端身份绑定租户与渠道作用域，禁止全局 wechat_openid 唯一约束；匿名或本机登记仍须按入口契约形成可信内部身份 |
| 开放平台 | API Key + HMAC 解析固定 tenant、integration、ServicePrincipal 和 scopes；应用治理凭据、机构执行凭据、渠道令牌与后台令牌互不替代。支持受控签发、轮换、停用及可选网络策略 |
| 委托用户 | 创建 Session 显式校验本租户 end_user_id，同时记录 ServicePrincipal 与 EndUser actor；externalUserRef 只作关联、审计和幂等，不能创建或覆盖内部身份、租户、角色或既有 Session 绑定 |

细节以 [SaaS 安全会话](../02-架构与设计/19-SaaS基础底座设计.md#3-可选-mfa-与真实安全会话)、[接口与事件契约](../02-架构与设计/04-接口与事件契约.md)和[工程授权规则](../../.agents/skills/nw-engineering/references/engineering-standards.md#身份权限与租户)为准。[ADR-001](../05-架构决策/001-身份与多租户隔离.md)保留应用内身份与双账号体系决策；其早期 Redis refresh 定位说明不覆盖现行权威设备会话与数据库授权模型。

### 1.2 多租户与资源隔离

| 资源 | 已批准要求 |
| :--- | :--- |
| 业务数据 | PostgreSQL RLS 与可信租户绑定共同隔离；连接复用、事务、缓存和后台任务不得保留另一租户身份。跨租户平台操作须有独立平台授权与明确目标 |
| 缓存与检索 | Redis 键使用租户命名空间；向量／全文检索强制租户及所属知识库过滤，查询命中不能代替对象授权 |
| Workflow 与 Session | 执行、会话、历史和恢复引用绑定真实 tenant 与所属对象；共享 Agent 不授予 Session 正文访问权 |
| 资源创建 | 当前功能及容量在真实创建事务内检查，并发请求不能以事务外计数绕过容量 |
| 运行与防滥用 | 速率限制、月度配额、资源容量和 Run 冻结预算分开控制，详见第 6 节 |
| 企业隔离 | 专属 Namespace／Schema／工作负载属于企业部署规划，须单独确定架构与验证，不能由当前 RLS 推导已交付 |

### 1.3 凭据、传输和执行安全

保留全链路 TLS 1.3 安全目标，实际证书、终止点与内外链路须在目标部署核验。PII／凭据保留 AES-256-GCM 存储加密目标，并按数据分类脱敏；库级 TDE 按部署可选。当前业务密文使用应用级 CryptoService 版本化 GCM 密钥契约；每租户 DEK／KMS／Vault 信封加密仍属[相关设计](../../harness-design/README.md)，不能写成当前已交付。

外部凭据由所属连接器／凭据能力管理，禁止放入 Workflow 配置、模型上下文、执行快照、普通日志或公开结果；仅在获授权 Provider 调用边界短时解析注入，Agent、Workflow 与开发者均不能读取明文。签发结果未知先核验或显式轮换，不能盲目重签。HTTPS、SSRF、DNS 和重定向地址检查按[连接器契约](../05-架构决策/003-最小连接器契约.md)及所属执行服务落实，Mock 本地例外须显式开启。第三方模板上架须安全审核，安装按声明权限审批。

代码执行和 Workflow script 沙箱已有本地实现与验证，默认关闭。启用须具备独立执行服务、镜像、资源约束、网络隔离、持久存储和隔离预览源；配置缺失拒绝执行，不回退宿主进程。非 root、只读根、最小 capabilities、禁止提权、CPU／内存／进程／输出约束、强制出站代理、DNS 重绑定防护及容器清理以[沙箱设计](../02-架构与设计/12-代码执行沙箱与产物交付.md)为准。Docker socket、平台秘密和业务目录不得暴露给用户容器；Docker 不等于虚拟机级强隔离，生产专用执行宿主与受限网络仍是部署前提。

工具超时、代码预算和总 deadline 按冻结策略与剩余 Run 预算执行，不采用覆盖所有工具的三十秒或执行总时长一百二十秒统一上限。gVisor／Firecracker 不作为当前交付能力。生产禁用 Core Dump，明文驻留最小化并尽力清零可控缓冲，不承诺托管运行时所有副本可擦除；日志和异常过滤 Authorization、API Key、token 与 PII，规则见[配置与凭据](../../.agents/skills/nw-engineering/references/engineering-standards.md#静态定义与配置)。

### 1.4 Prompt Injection 与公开输出

保护 System／Workflow Prompt、工具副作用、检索／记忆、凭据／PII 和人工确认。威胁包括直接越狱、工具参数污染、检索间接注入、多轮记忆投毒及输出套取。标签、分隔和 Prompt 加固只作辅助，不能作为充分控制。

| 控制 | 已批准要求 |
| :--- | :--- |
| 最小权限 | 模型只见当前挂载授权能力；可见不等于获准，实际调用校验权限、对象与预算，禁止动态挂载未审批工具 |
| 参数与输入 | 类型化参数经 Schema、字符／字节／附件预算校验；拒绝额外字段和显式超限，不截断原始输入，ID／金额等保留类型和范围约束 |
| 确定性确认 | 高风险副作用按领域契约走确定性节点或强制 HITL，模型不能跳过，文本、历史与工具结果不能伪造确认 |
| 不可信资料 | RAG、外部内容、工具结果和记忆作为数据，不改变授权和优先级；Grounded 回答不执行资料指令，引用与回答分离 |
| 输出保护 | 检查秘密、内部路径、未投影快照与跨用户敏感信息；模型不能自证状态、归属或可信引用 |
| 发布评测 | 使用固定注入／越权调用集核验直接影响的控制；已知模板规则与异步分类仅作辅助检测，不替代确定性授权 |

正则拦截、异步小模型和完整 DLP 的实际覆盖须另有证据，不能由需求条目推定全面启用。输入校验不替代[Runtime 上下文裁剪、摘要及投影](../../harness-design/03-上下文视图与执行优化.md)，也不允许这些过程改写输入或授权事实。

## 2. 可靠性与可用性

### 2.1 内部 SLO 与合同边界

内部可用性目标沿用 [ADR-004 套餐草案](../05-架构决策/004-配额与套餐.md)，本文不复制套餐矩阵。内部 SLO 用于研发、告警和容量规划，不代表已测量结果或合同 SLA。合同可用性、单租户／平台 QPS、支持等级、维护排除项和赔付均为 **TBD**，依[相关设计](../02-架构与设计/14-用量与账单设计.md)确定，未签约且未验证的 99.xx% 不进入对外承诺。

企业灾备保留 **RPO < 1 分钟**内部部署目标，须在指定环境验证备份、连续归档和恢复业务一致性，合同承诺仍为 TBD。隔离 PITR 演练不能证明生产满足该值；RTO 待部署与合同确定，本文不新增数值。

### 2.2 持久恢复与外部未知结果

执行状态持久化，进程崩溃按原事实恢复；checkpoint、revision／fencing、事务写权、挂起及回调遵循 [Harness 非功能需求](../../harness-design/01-Agent-Workflow协作引擎-MVP需求分析.md#5-非功能需求)和[状态契约](../../harness-design/03-核心对象模型与状态机.md)。查询、回执读取和事件恢复不能自动重放业务副作用。

管理任务按持久租约、逐行事务与原回执恢复，取消不回滚已提交行。Outbox 保留 SMTP accepted/rejected/unknown，受理不等于终端收件。代码退出、文件持久化与成果发布分别记录；断线、取消或终止容器不证明既有公网副作用未发生。未知结果不能通过重跑、重复发送或覆盖终态消除，细则见 [SaaS 底座](../02-架构与设计/19-SaaS基础底座设计.md)和[沙箱任务阶段](../02-架构与设计/12-代码执行沙箱与产物交付.md#4-任务阶段与中断)。

### 2.3 扩展与发布

横向扩展遵守真实持久状态与唯一写权，网关或宿主不另建 Runtime 状态机。新模型经 ModelProvider／adapter 接入，渠道、记忆与工具协议按所属边界装配；HTTP 和 MCP Streamable HTTP 已装配不等于 gRPC 等后续协议已经交付。无状态服务、LB 和队列削峰是容量方向，不证明当前环境完整高可用。构建、readiness、业务验收与生产可用性分别取证，两副本滚动发布目标见第 3 节。

## 3. 性能与容量

### 3.1 内部延迟目标

| 指标 | 内部目标 | 测量边界 |
| :--- | :--- | :--- |
| 对话首 Token（TTFT） | P50 < 1.5 秒 | 不含冷启动，记录模型、缓存和网络条件 |
| 简单工作流完成 | P50 < 30 秒 | 少工具、单轮确认，注明人工等待口径 |
| 复杂多步完成 | P50 < 90 秒 | 多工具，HITL 等待另计；不作为总预算上限 |

对话用 SSE，人工坐席用 WebSocket，见 [ADR-002](../05-架构决策/002-实时通信协议.md)。容量按 SSE 长连接与短连接 REST 组合测量，首 Token、重连、完整执行与第三方长尾分别观测。

### 3.2 容量假设与候选验收

以下仅用于推演，不是实测结果或商务承诺。

| 假设 | 参考值 |
| :--- | :--- |
| 平均会话时长 | 8–12 分钟 |
| 会话消息 | 8–15 轮，沿用用户与助手合计原规划口径；压测前须明确消息与轮的统计单位 |
| 活跃会话同时等待 LLM | 约 15%–25% |
| LLM TTFT P50／P95 | 0.8 秒／2.5 秒，网关与模型合计 |
| 工具 HTTP P50 | < 300 毫秒，不含第三方长尾 |
| 租户速率限制 | 读取套餐有效策略与覆盖，数值见 ADR-004 |

| 指标 | 远期规划 | MVP-0 候选验收目标 |
| :--- | :--- | :--- |
| 入站 QPS | 平台峰值 10,000 | 单环境稳态 ≥ 100 QPS 合成对话流量，错误率 < 1% |
| 在线会话 | 100,000，SSE＋REST 组合规划 | 单环境 ≥ 1,000 并发 SSE 会话，可完成首 Token 和重连 |
| 水平扩展 | 服务扩容、LB 与队列削峰 | 编排与网关至少两副本滚动发布，保持对话可恢复，允许 SSE 重连 |

候选目标保留原稿建议门禁地位，正式采用前确定资源规格、持续时间、依赖、缓存和失败统计。10,000 QPS／100,000 并发不能写成 MVP-0 已达标指标、合同或免费套餐承诺。

### 3.3 知识链路观察目标

沿用以下内部观察数值，不作为合同或 MVP-0 硬门槛；图谱、GraphRAG 和图抽取不在产品范围。

| 指标 | 内部观察目标 | 边界 |
| :--- | :--- | :--- |
| 意图识别与实体抽取 | P95 < 200 毫秒 | 仅不含外部 LLM 的路径，不能套用到 LLM 抽取 |
| 向量检索 | P95 < 150 毫秒 | TopK=5，ANN |
| LLM 抽取（非流式） | P95 < 8 秒 | Prompt 填充与调用，依赖模型 |
| LLM 生成首 Token | P95 < 3 秒 | 知识生成口径，区别于普通对话 P50 |
| 结构化入库 | P95 < 1 秒 | 同步单条写入 |
| 批量导入 | 10 页／秒 | 解析＋抽取＋入库，吞吐不称 P95 延迟 |

没有实际测量不得宣称通过。容量规划、内部目标与合同容量分别存在，合同 TBD 不取消内部目标。

## 4. 数据生命周期与部署

### 4.1 留存、撤销与清理

生命周期由领域持有，清理不得删除仍被恢复、正式成果或调查引用的数据。租户对话留存、导出／删除与注销等待期是治理目标；Redis TTL 不等于会话删除，统一保留期不能覆盖 Session、Runtime、工作区、知识、审计和费用事实。

| 数据域 | 约束与当前边界 |
| :--- | :--- |
| Runtime、消息和记忆 | 持久化、恢复与事实归属见 Harness；缓存失效不删除执行事实，不在本文另定 PG 元数据＋Redis 热消息存储架构 |
| 公共文件和管理任务 | 引用保护与保留期按所属规则，不跨域删除 Session 附件、工作区或 Artifact |
| 候选和正式成果 | 候选执行文件／独立证据默认七天，先阻止访问再清理；正式文件、来源和 planned/finalizing hold 按 Session／生命周期保护，不能套用候选期限 |
| 安全审计 | 仅追加，清理默认关闭；默认保留 180 天，显式策略 30–3650 天，调查保护阻止删除，精确冻结与执行边界见 SaaS 设计 |
| 终端用户删除 | 保留标记删除、画像匿名化、热消息清除和执行上下文脱敏目标；原稿三十天可撤回作为待落实规则，完整删除／撤回链路不能声明已交付 |

会话归档、回放和用户删除整体范围见[相关设计](../../harness-design/README.md)。三十天撤回不能覆盖审计／调查保留、费用事实或正式成果引用；实际冲突须由所属领域裁定，本文不代定删除顺序。操作授权与关联清理遵循[清理与保留规范](../04-指南与运维/11-数据清理与保留规范.md)，生命周期目标不授权任意清空数据库。

### 4.2 数据主权与私有化规划

| 模式 | 规划边界 |
| :--- | :--- |
| Cloud | 平台托管基础设施，实际区域与供应商出口按部署核验 |
| Hybrid | 控制／执行面与客户数据面分离，敏感数据留机构侧，明确最小上送元数据和断连行为 |
| On-Premise | 机构内网整套部署，自有／本地模型、离线依赖、安装升级和恢复形成可验收闭环 |

Compose／K8s 资料或本地部署不证明完整私有化发行交付。驻留涵盖数据库、文件、缓存、索引、Provider、备份和遥测；每租户密钥、跨区策略、Hybrid 与离线发行见[相关设计](../../harness-design/README.md)。外部 IdP 为后续可选集成，不改变双账号隔离；节点／年费等收费方式按合同确定。

### 4.3 备份与部署验收

数据库、持久文件和必要密钥版本形成一致恢复依据，备份保护秘密；恢复至明确命名的全新隔离目标，不自动启动业务或切流。备份可读不等于恢复成功，隔离 PITR 不等于生产连续归档。文件与元数据恢复后重新核验归属、有效期及权限。

目标环境分别验证就绪、真实身份／隔离、邮件交付、监控抓取／告警、备份凭据／存储、WAL 连续性和恢复业务一致性。方法见 [SaaS 配置与备份](../02-架构与设计/19-SaaS基础底座设计.md#9-配置备份与验收边界)和[部署指南](../04-指南与运维/01-开发与部署指南.md)，本地实施记录不作为生产可用性证明。

## 5. 可观测性与审计

默认结构化日志和 Prometheus 指标，技术追踪可用 OpenTelemetry → OTLP，Grafana Alloy 可选，栈见 [ADR-005](../05-架构决策/005-技术栈版本锁定.md)。Grafana、Loki、Jaeger／Tempo、Alertmanager 等方案不能自动视为当前部署已启用。

| 观测面 | 已批准要求 |
| :--- | :--- |
| 服务与业务 | QPS、延迟、错误率、Token、工作流聚合与配额耗尽分别表达；租户视角由授权日志、追踪或业务聚合提供，不把无限增长身份作指标标签 |
| 技术追踪 | W3C trace_id/span_id 关联当前尝试；可采样导出，不替代持久事实 |
| 持久因果 | input_id/root_input_id/event_id/caused_by_event_id 跨挂起、回调和重启关联，渠道另记 channel_type；恢复、审计、回放和费用读取所属事实 |
| 日志与投影 | 凭证、Token、Prompt 全文、私有思维链与未投影快照不进入普通日志或 TraceProjection；PII 脱敏和租户检索受当前授权约束 |
| 安全审计 | 追加真实操作者、对象、动作和结果；拒绝事实受控保留，删除仅由保留执行器在政策、期限及调查保护条件内执行 |
| 告警 | 平台／租户／Workflow 风险按所属需求设阈值；规则校验通过不等于实际抓取或通知送达 |

日志级别、字段、基数与脱敏见[工程观测规则](../../.agents/skills/nw-engineering/references/engineering-standards.md#事务日志与可观测性)。监控须验证网络、端点、HTTP histogram 与接收器。SQL 检查、promtool 检查与隔离恢复演练分别记录适用环境和结果；这些检查不证明生产已配置。

## 6. 用量、配额与费用完整性

### 6.1 类别与统计窗口

套餐数字及内部 SLO 草案唯一维护于 [ADR-004](../05-架构决策/004-配额与套餐.md)，有效策略读取 plans 及获授权覆盖，各模块不得硬编码。统计为北京时间（Asia/Shanghai）自然月，租户不可变更时区；速率限制防滥用与月配额分开。

| 类别 | 独立事实与要求 |
| :--- | :--- |
| 功能授权 | 套餐功能关系与机构覆盖；菜单不授予功能或动作 |
| 资源容量 | Agent、Workflow、知识库、成员、渠道、公共文件字节和管理任务在创建事务计量；有效值 0 表示无新增容量，null 表示不限 |
| 月用量 | 请求次数、调用次数与 Token 分开，不以请求数估算 Token |
| 速率限制 | 按有效策略控制频率，与月配额和费用余额分离 |
| Run 预算 | 受理／准备时冻结，后续套餐变化不改写原预算、准备引用或历史用量 |

请求配额由已受理 Input 持久事实派生，无模型调用仍计一次，重复 inputId 幂等只计一次，不另建 requestId 业务链。并发容量见 [SaaS 配额](../02-架构与设计/19-SaaS基础底座设计.md#23-租户功能和资源配额)，执行预算与计量契约见 Harness。

### 6.2 用量与费用完整性

Usage Ledger 保存不可变原子事实，request 根仅承担配额计数和关联，不计费，模型／Token／金额显示不适用。无调用、执行中、失败和缺失用量分别表达，未知不记零。LLM／Embedding 实际 Token 仅取供应商 usage，缓存／推理子集不重复累计，预算估算不落账。

供应商成本与机构应收独立，计量单位、价格与汇率依事实冻结。免费明确零价，缺用量或售价阻止对应应收封账；已封账不可改写，迟到与更正追加补充／调整并留审计。状态、精度和幂等见[用量与账单设计](../02-架构与设计/14-用量与账单设计.md)和[Runtime 用量契约](../../harness-design/03-核心对象模型与状态机.md#510-端到端轨迹与用量契约)。

依据 ADR-004 最新修订，当前按量出账不收套餐基础费、不抵扣套餐额度。支付、退款、税务发票和合同 SLA 仍属后续；open 只表示封账待结算，不表示支付成功。套餐草案不能覆盖当前账单规则。

### 6.3 耗尽与拒绝

| 场景 | 已批准行为 |
| :--- | :--- |
| 对话渠道月配额耗尽 | HTTP 200＋结构化友好卡片，说明额度与后续处理，不裸返 429 |
| 管理 API／OpenAPI 月配额或限流拒绝 | HTTP 429、Retry-After 与稳定错误码，按所属契约表达 |
| 资源创建容量不足 | 写入前拒绝，现行 SaaS API 返回 409 配额冲突，不能套成月调用耗尽 |

渠道差异仅用于对应配额／限流，普通身份、权限与业务错误仍用真实 HTTP 契约。预警、暂停、欠费宽限与恢复由受控策略驱动，停新行为不删除历史 Session、Execution、Usage 或封账记录；商业联动边界见[相关设计](../02-架构与设计/14-用量与账单设计.md)。
