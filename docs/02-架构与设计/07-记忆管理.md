## 1. 边界

记忆、会话日志、关系状态、机构知识和执行账本的权威关系直接引用 [Harness 03](../../harness-design/03-核心对象模型与状态机.md#10-事实源关系)；工作、短期、会话、中期与长期记忆的载体见 [Harness 02](../../harness-design/02-微内核插件架构实现思路.md#57-会话状态记忆与生命周期)。宿主不按这些产品称谓另建权威存储。

机构复用人工服务话术和表达风格的对象归属见[会话学习设计](22-会话话术与风格学习设计.md#3-对象与唯一事实源)。该能力通过机构知识与 Agent 配置接入，患者个人记忆继续遵守本文引用的归属和访问契约。

## 2. MVP-0 MemoryPort

MemoryPort 的语义与记忆治理流程见 [Harness 02](../../harness-design/02-微内核插件架构实现思路.md#58-记忆协议类型--提取--路由--检索--更新--过期)，宿主存储适配责任见 [Harness 03](../../harness-design/03-核心对象模型与状态机.md#76-sdk-ports-与适配器责任)。本文不复制端口字段、状态或阶段验收。

## 3. 上下文管线

宿主注册 Provider、配置预算并提供存储适配；ContextPipeline 的阶段、授权、快照和回放规则见 [Harness 03](../../harness-design/03-核心对象模型与状态机.md#56-stateful-agent-context)。模型上下文的组装规则不由宿主检索回调另行定义。

## 4. P1 产品化

产品 schema、提取审核、冲突治理、衰减、来源解释和管理界面范围见 [Harness 04](../../harness-design/04-后续阶段需求扩展-P1-P3.md#fr-9-记忆产品增强p1)。宿主配置和界面通过公开的查看、纠正与删除能力接入，实际行为与支持范围需核对当前源码，并按对应场景验证。

机构记忆治理页面使用 `GET /api/v1/memories/page` 按范围、智能体、终端用户、状态和关键词读取记忆，查询结果通过 `next_cursor` 继续加载；旧数组接口仍由其他消费者使用。关键词在符合机构和筛选条件的权威事实正文中匹配主体、关系和内容，每次请求最多扫描 1000 条；即使当前批次没有匹配项，只要返回游标就仍可继续查找。游标按创建时间和事实 ID 排序，不提供跨请求一致性快照；翻页期间新增或改变状态的事实需刷新后重新查看。接口与权限以 [MemoryGovernanceController](../../backend-java/skillforge-institution-service/src/main/java/com/skillforge/institution/controller/MemoryGovernanceController.java) 和 [MemoryGovernanceService](../../backend-java/skillforge-institution-service/src/main/java/com/skillforge/institution/memory/MemoryGovernanceService.java) 为准。

关键词按不区分大小写的字面量匹配，不解释通配符或查询语法；除原始正文外，也匹配 JSON 字符串值解码后的原文，因此路径中的反斜杠、引号和换行不要求用户填写 JSON 转义形式。新增的解码匹配逐个检查字符串值，不跨不同字段拼接。搜索不要求正文满足某一产品 schema；无法解码的正文仍保留原始文本匹配。该规则用于治理列表查询，不替代 Runtime 召回的过滤、排序或权限规则；表格正文仍按现有结构化展示。

治理页的状态动作与上述六态契约一致：待确认事实提供批准、拒绝；活动或待确认事实可遗忘，已衰减或已遗忘事实可恢复，已拒绝和已归档事实不提供状态迁移入口。审核标记不能替代当前事实状态决定操作。恢复使用原事实 ID 和预期版本，后续运行按原归属重新检索，不修改已开始运行的冻结请求。

## 7. 宿主持久化与衰减投影

宿主记忆治理、后台提取与衰减、提案来源校验统一通过所属领域的 MyBatis Mapper/XML 访问关系数据库。后台任务从全局活跃租户目录发现租户，在每个租户任务的作用域显式设置并恢复 `TenantContext`；MyBatis RLS 拦截器绑定实际执行连接，业务组件不自行设置连接租户。

`agent_runtime_memory_usage_projection` 是宿主衰减投影，由宿主 schema 管理。事实 head 从非 `ACTIVE` 推进到 `ACTIVE` 时，宿主触发器在该 head 更新的同一事务中重置衰减并更新衰减基准时间；没有投影行时创建初始行。失败整体回滚，同一 revision 的重放不重复重置。触发器按调用者权限执行并遵守 RLS，Runtime SDK 不依赖该投影表，宿主治理服务不再执行第二次独立重置写入。
