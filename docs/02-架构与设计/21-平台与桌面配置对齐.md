# 平台与桌面配置边界

平台宿主与独立桌面宿主使用同一 Runtime，分别拥有配置来源、身份授权、工具与持久化装配。配置项存在不表示对应能力已接入；运行行为以当前源码和对应场景的验证为准。

## 平台宿主

平台按租户、Agent 与任务维护模型、能力、预算和运营配置。新受理 Run 使用发布时选定的配置，恢复使用原冻结材料；修改默认值不覆盖已有数据库修订。根任务、Run、Stage 与成员额度由同一来源派生，模型、工具和知识消耗分别计量。结果未知的外部调用不得因配置调整而自动重发。

- 默认值与配置字段见 [OperationalSettingsRegistry](../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/settings/OperationalSettingsRegistry.java) 和 [OperationalSettingsDefaults](../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/settings/OperationalSettingsDefaults.java)。
- 任务预算派生见 [ChatBudgetSettings](../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/runtimeconfig/ChatBudgetSettings.java)，Worker 装配见 [ExecutionHostWorker](../../backend-java/agent-runtime-spring-boot-starter/src/main/java/com/skillforge/runtime/starter/ExecutionHostWorker.java)。
- 模型协议、容量和能力必须匹配实际端点与完整适配器，见 [model adapter](../../backend-java/agent-runtime-adapter-model/src/main/java/com/skillforge/runtime/adapter/model/)。模型目录元数据不能替代流解析、历史投影、计量或恢复实现。

## 独立桌面宿主

桌面使用本地 Runtime、文件与进程工具、SQLite 持久化及用户配置的云端模型 API，不依赖平台业务服务。工具权限、模型配置和工作区由桌面组合根维护，平台的租户预算、Worker 参数、容器配额和计费配置不自动适用于桌面。

文件读取预览、完整文件修改容量和命令前台等待分别由实际工具约束。命令超时或持久化会话不表示存在后台 Job 管理；文件路径约束和用户确认也不构成操作系统级沙箱。未实现的搜索、图片、后台进程或隔离能力不能仅通过配置开关启用。

桌面策略、模型绑定、文件与进程实现见 [desktop Host](../../backend-java/agent-runtime-desktop-host/src/main/java/com/skillforge/runtime/desktop/)，用户配置及运行方式见[桌面客户端](../../desktop-client/README.md)。

## 配置验证

修改配置应验证当前消费者、新 Run 生效、旧 Run 冻结恢复、显式值保留及失败/UNKNOWN 边界。供应商协议、桌面操作系统和容器资源限制分别验证，不用单次模型请求或元数据检查代替完整场景验收。

Runtime 语义见 [Harness](../../harness-design/README.md)，平台启动见[开发与部署指南](../04-指南与运维/01-开发与部署指南.md)，容器执行见[代码执行指南](../04-指南与运维/09-代码执行与产物运行指南.md)。
