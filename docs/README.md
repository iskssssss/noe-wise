# 灵知 文档

本目录提供产品、宿主平台、接口、开发与运维文档；[harness-design](../harness-design/README.md)维护 Agent Runtime 的需求、架构、对象模型与执行契约。首次阅读可从[项目 README](../README.md)和[产品概述](01-产品与需求/02-产品概述.md)开始。

项目处于预发布阶段。需求与架构中标为目标、规划或未实现的内容不代表已交付；源码、配置与当前测试决定具体版本的实现情况。运行方法以指南为准，生产适用性需要在目标环境验证。
