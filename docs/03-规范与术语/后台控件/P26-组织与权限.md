# P26 组织与权限逐控件规格

本页定义稳定对象与验收断言；实现/验证状态归[验收索引](../../08-数据与工具/ui-acceptance-index.json)。共同原子合同、规则映射及桌面验收边界见[P26–P32 共同合同](../06-后台逐控件规格.md#基础页面共同原子合同)。

平台与机构入口分别为 `/platform/foundation/access`、`/admin/foundation/access`。主实现为 [AccessPage.vue](../../../frontend-shared/src/foundation/access/AccessPage.vue)，数据类型见 [types.ts](../../../frontend-shared/src/foundation/access/types.ts)，权限/输入/版本权威来源为 [FoundationAccess](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/access/FoundationAccess.java)、[FoundationOrganizationService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/access/FoundationOrganizationService.java) 与 [AccessValidation](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/access/AccessValidation.java)。接口路径以下以宿主注入的 `foundation/access/` 为根；邀请使用 `foundation/security/invitations`。

读取要求 `foundation.access.read`；组织编辑要求 `foundation.access.organization.manage`，角色编辑要求 `foundation.access.role.manage`，新增成员同时要求两者；邀请要求 `foundation.security.invitation.manage`；资源授权仅机构且要求 `foundation.access.resource.manage`。多角色权限与数据范围取并集，内置角色只读；分享不补充动作权限，Session 历史不参与资源分享。权限变化后的表单与确认须重新判权，不能沿用打开时资格。
