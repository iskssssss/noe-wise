# P08 智能体模板列表实际控件合同

本表依据 [AgentTemplatesPage.vue](../../../frontend-platform/src/views/platform/AgentTemplatesPage.vue) 描述当前页面；保留编号供验收索引使用。具体接口以 [api/index.ts](../../../frontend-platform/src/api/index.ts) 为准。

| 子ID | 控件或行为 | 当前实现 |
|---|---|---|
| P08-C01 | 标题 | 标题“智能体模板”，说明公共定义的编辑、验证与发布。 |
| P08-C02 | 新增 | 拥有 platform.agent_definitions.create 时显示新增入口，导航到新建页并携带列表上下文。 |
| P08-C03 | 状态筛选 | 下拉可选 draft、published、deprecated、archived 或清空；点击查询后生效。 |
| P08-C04 | 名称筛选 | 输入名称并点击查询或提交表单；当前没有分类筛选控件。 |
| P08-C05 | 列表摘要 | 显示服务端 total。 |
| P08-C06 | 名称与详情 | 模板名称是链接，使用 definition_id 打开详情并携带列表上下文。 |
| P08-C07 | 模板标识 | 当前表格没有模板标识列。 |
| P08-C08 | 发布修订 | 表格显示 version。 |
| P08-C09 | 分类 | 表格显示 category；当前没有分类筛选。 |
| P08-C10 | 状态 | 表格通过 statusLabel 展示状态。 |
| P08-C11 | 安装次数 | 表格展示 install_count。 |
| P08-C12 | 更新时间 | 当前表格没有更新时间列。 |
| P08-C13 | 行操作 | 列表没有发布、删除、下架或归档操作列；名称链接进入详情。 |
| P08-C14 | 进入维护 | 点击名称进入定义详情；具体草稿及发布操作以详情页为准。 |
| P08-C15 | 发布 | 列表页没有发布按钮。 |
| P08-C16 | 删除 | 列表页没有删除按钮。 |
| P08-C17 | 下架与归档 | 列表页没有下架或归档按钮。 |
| P08-C18 | 加载、空态与错误 | useResource 读取结果，空态区分加载、错误和无结果；页面未提供独立重试按钮。 |
| P08-C19 | 分页与返回上下文 | 每页 20 条；初始读取 list_name、list_status、list_page，详情和新建链接携带已应用筛选与当前页；查询与翻页不更新当前 URL。 |
| P08-C20 | 未实现的列表控件 | 当前没有复制、右键菜单和行内写操作；不得作为已实现能力。 |

## 待验证场景

以下为验收要求，不表示已执行：核对已应用筛选、分页请求、服务端 total 和列表结果一致，未提交的输入不应改变当前结果；读取失败与空列表应可区分。同名模板分别绑定真实 ID，进入详情或新建后返回时核对筛选和有效页码；权限不足不能通过直接请求获得写入能力。发布、删除和归档等行为在实际详情入口分别验证，不把列表页未提供的按钮当成已实现功能。
