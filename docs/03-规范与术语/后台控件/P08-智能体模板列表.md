# P08 智能体模板列表实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

源码：[AgentTemplatesPage.vue](../../../frontend-platform/src/views/platform/AgentTemplatesPage.vue)、[api/index.ts](../../../frontend-platform/src/api/index.ts)。列表 API 支持 `status/category/name/page/limit`；页面地址用 `status/search/category/page/size` 保存已提交条件，其中 search 映射 API name、size 映射 limit。刷新、浏览器前进后退和复制链接恢复相同查询；列菜单仍未实现。

| 子ID | 真实控件与绑定 | 外观/文案（历史 key） | 数据、可见/可用条件 | 动作、状态与失败恢复 | 验收断言 |
|---|---|---|---|---|---|
| P08-C01 | 页面标题和副标题 | `platform.agentTemplates.title/subtitle`；页头 | 始终可见 | 无动作 | 修改已发布模板生成新草稿的说明与实际路由行为一致 |
| P08-C02 | 新建模板按钮 | `platform.agentTemplates.create`；primary、小号；`platform_admin` | 始终可见但权限控制 | 跳 `/platform/agent-templates/new`；不创建服务端草稿 | 重复点击不产生写请求；无权限不可执行 |
| P08-C03 | 状态筛选按钮组 | `agentTemplates.statuses.all/draft/published/deprecated/archived`；当前选中 primary，其余 secondary | `filter` 默认 all；选项来自固定状态映射 | 更新 status query 并回第一页；缺失或非法状态恢复 all；只使用已提交名称/分类，不把输入草稿一并提交 | 选中状态与请求完全一致；非法 query 规范化为默认值，未提交搜索草稿不改变当前请求 |
| P08-C04 | 名称和分类筛选 | `agentTemplates.filters.name/category`；两个 `ElInput`，查询与重置复用通用动作文案 | `nameDraft/categoryDraft` trim 后分别提交为 API `name/category`；空值省略；与 status 共同构成服务端筛选 | Enter（非输入法合成）或查询将规范化条件写入 URL 并回第一页；重置清空三项及对应 query；不在当前页二次伪过滤 | 请求携带提交后的 name/category/status；服务端返回页原样进入表格；未提交草稿不改变结果；重置不遗留条件 |
| P08-C05 | 表格摘要 | `platform.agentTemplates.tableSummary({count:list.total})` | total 来服务端 `AgentTemplateItem` list | 只读 | total 不用当前页长度；刷新/筛选后摘要更新 |
| P08-C06 | 名称列与维护入口 | 表头 `.table.name`；值 `row.name` | row id 绑定；只有 draft/published 有维护按钮 | 行按钮 draft 编辑、published 创建新版本（当前都进入同一详情路由，published 修订语义需详情确认） | 同名不同 id 可区分；按钮不冒泡导致错误导航 |
| P08-C07 | 模板标识列 | 表头 `.table.templateKey`；`row.template_key` | 字符串，完整显示 | 只读；复制能力当前未实现 | 长标识不丢字符；若提供复制需绑定 row.id/key，不得转数字 |
| P08-C08 | 版本列 | 表头 `.table.version`；`row.version` | 版本属于当前 item，操作绑定 id | 只读 | 删除/发布确认显示同一版本，不把定义 id 当版本 |
| P08-C09 | 分类列 | 表头 `.table.category`；`row.category` 经 `formatEmpty` | nullable | 只读 | 空分类使用统一空值展示；分类筛选作为服务端条件，不依赖当前页内容 |
| P08-C10 | 状态列 | 表头 `.table.status`；`ElTag` + `statusLabel` | row.status，tone published success/deprecated warning，其它 neutral | 只读 | 状态文字来自 `.statuses`；未知状态保留原文并不显示错误动作 |
| P08-C11 | 安装量列 | 表头 `.table.installs`；`row.install_count` 经 `formatEmpty` | optional number；null 与 0 分开 | 只读 | null 不渲染为 0；统计口径当前 DTO 未说明，标待绑定 |
| P08-C12 | 更新时间列 | 表头 `.table.updatedAt`；`formatTime(row.updated_at)` | optional timestamp | 只读；排序当前未开放 | null 不用当前时间；若将来排序必须由 API 支持 |
| P08-C13 | 操作列和行权限 | 表头 `.table.operation`，sticky right；所有写按钮 `platform_admin` | 行 status 决定动作：draft edit/publish/delete，published revise/deprecate，deprecated archive；`busyRows` 以 row id 记录当前动作 | 按目标 id 调 API；同一行 busy 时锁定该行全部入口并显示对应 loading，其他行仍可操作 | 表格刷新/分页后操作不串行；一行待决不冻结其它行；无权限或状态不符不能执行隐藏写请求 |
| P08-C14 | 草稿编辑/已发布修订按钮 | `actions.edit/revise`；secondary | draft/published 可见 | 进入详情；published 应明确“基于版本创建草稿”而不是编辑只读记录 | 进入详情时加载对象 id 与点击行一致；published 详情不得直接变更发布记录 |
| P08-C15 | 发布按钮与确认 | `actions.publish`；确认 `.publishTitle/.publishContent`、确认按钮 `.actions.publish` | 仅 draft、platform_admin；目标行 action 为 publish 时 loading | 确认后 publish；成功 Toast `.published` 并刷新；finally 释放该行 busy | 未验证草稿不能发布（详情负责）；失败不从列表移除；同一行重复点击只一请求，其它行不受影响 |
| P08-C16 | 删除按钮与确认 | `actions.delete` danger；`.deleteTitle/.deleteContent`，参数包含目标 name/version | 仅 draft；目标行 action 为 delete 时锁定 | 删除需确认，调用 remove(id)，成功 Toast `.deleted`、刷新 | 确认显示目标名称/版本；失败保留行并释放 busy；已发布版本无删除按钮 |
| P08-C17 | 下架/归档按钮与确认 | `actions.deprecate/archive`；对应 title/content 带 name/version，Toast `.deprecated/.archived` | published 允许下架，deprecated 允许归档；busy 仅绑定目标行 | 目标 id 写入；成功刷新，失败保留行并释放 busy | 下架与归档不是同一状态；按钮、文案和 API 分别一致；其它行在目标写入期间仍可操作 |
| P08-C18 | 加载、空态、错误和重试 | 错误 `agentTemplates.loadFailed`，空 `emptyState`，`Vben VXE Grid` retry | `usePagedList` loading/error/total | retry 读取已提交筛选；缓存列表重新激活时 `useWorkspaceListRefresh(refresh)` 读取最新事实 | 失败不显示“暂无模板”；返回缓存页刷新数据但保留筛选、页码和滚动；当前页失效按分页组件修正，不循环请求 |
| P08-C19 | 分页与返回上下文 | `Vben VXE Grid` page/pageSize/total；已提交条件和分页来自 URL，未提交输入仅留页面实例 | API page/limit | 页码/页大小变更更新 URL；初次进入、浏览器前进后退恢复条件，非法页码或页大小恢复默认值；服务端缩页后 replace 当前 URL；详情返回刷新当前条件 | 操作成功后保留筛选与有效页码；末页失效只回退并读取有效页，不循环请求；刷新和复制链接恢复同一查询，未提交草稿不进入 URL |
| P08-C20 | 当前实现缺口：复制、右键、详情入口文案和局部失败 | 无 copy、右键菜单、单行错误恢复、名称链接；旧 06 项需补接线 | 不把未实现控件纳入已实现清单 | 等真实控件/API/权限来源后补规格 | 草稿不宣称 16 项全部已实现；明确本列表是源码盘点结果 |
