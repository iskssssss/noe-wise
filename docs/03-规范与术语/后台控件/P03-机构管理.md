# P03 机构目录与工作台入口控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准；本文只约束业务字段、状态和验收编号。

当前机构入口采用“目录定位机构、工作台完成维护”的结构，目录只展示独立 Tenant，不展示机构内部部门。选择节点仅改变维护目标，不切换登录身份或扩大权限。现有编号和历史证据保留；旧 Vben、VXE、平面列表及 i18n key 只用于历史追溯，不证明当前源码仍存在相同控件。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

当前源码入口为 [TenantsPage.vue](../../../frontend-platform/src/views/platform/TenantsPage.vue)，页面组合见[平台机构工作台](../../../frontend-platform/src/views/platform/InstitutionWorkspacePage.vue)，目录展示见 [InstitutionDirectory.vue](../../../frontend-shared/src/institution/InstitutionDirectory.vue)，目录装载见[平台目录适配器](../../../frontend-platform/src/workspace/directory.ts)与[机构目录适配器](../../../frontend-admin/src/institution/workspace.ts)。机构详情与分区合同见 [P04](P04-机构详情.md)，连续开通、映射和执行凭证领域仍归 [P23](../06-后台逐控件规格.md#p23-机构开通映射与执行凭证)，授权与部署领域仍归 [P24](../06-后台逐控件规格.md#p24-平台直授与机构公共-agent-部署)。

| P03-C41 | 刷新机构目录按钮 | “刷新机构目录”；loading | 读取中显示忙碌；不修改当前目标及业务输入 | 只重读目录；失败保留错误和可恢复入口；401/403 按身份边界清理不可继续展示的数据 | 刷新不重发创建、授权或部署，不解除 UNKNOWN 写入保护；迟到目录响应不能覆盖新身份数据 |
| P03-C42 | 目录错误与空态 | `ElAlert`；“当前没有可展示的机构”“没有匹配的机构” | 重复 ID、循环关系及接口错误为错误；只有成功无项才为空态 | 清除查询或刷新读取；当前目标未出现时显示“目录可见范围与业务操作权限分别校验” | 读取失败不显示为无机构；目录缺少目标不自动换成另一机构或授予关系读取权限 |
| P03-C43 | 节点名称、状态与标识说明 | 名称按钮、状态文本、完整 `title` 提示 | 选中状态使用真实 id；未知状态保持可读，不能伪装正常 | 长名称可查看完整提示；无效关系进入目录错误 | 长名称、同名节点和长 ID 可区分；浅色与深色主题下选中、悬停及焦点状态可辨 |
| P03-C44 | 机构树键盘操作 | 节点按钮采用单一可聚焦项与可见焦点 | 当前可见节点参与方向键、Home/End；原生 Enter/Space 选择按钮 | 上下移动，右键展开或进入子级，左键折叠或返回可见父级；虚拟节点先滚动再聚焦 | 不因虚拟化丢失目标焦点；离开保护拒绝导航后仍高亮原目标；搜索组合输入不意外选择节点 |
| P03-C45 | 窄窗口机构选择抽屉 | “选择机构”；左侧 `ElDrawer` | 内容区收窄时由共享工作台收拢机构目录，右侧单栏 | 抽屉复用同一搜索与目录数据；选择目标受未保存和在途保护 | 1440、1052、768 像素窗口分别实际检查；抽屉关闭后焦点返回触发入口，取消切换保留原目标 |
| P03-C46 | 新增或接入机构入口 | “新增或接入机构”；primary | 平台具有普通机构创建或外部机构开通权限时显示；流程各步继续独立校验权限 | 导航到 `section=onboarding`；普通创建、外部开通和已有机构关联按用户选择调用原接口 | 不重复要求手填已选机构 ID；打开流程无写入；没有相应动作权限的方式不可提交 |
| P03-C47 | 普通机构创建结果查证 | “按原标识核对”“使用已找到的机构继续”等当前源码文案 | 普通创建没有幂等重发协议；UNKNOWN 冻结原 slug，原密码仅留当前交付流程 | 只通过原 slug 查询；查不到仍保留未知结果，不能自动再次 POST；找到后明确仅证明机构存在并提示核对管理员账号 | 不把查到同 slug 等同完整原操作成功；不生成替代 slug 或重建管理员；导航与通知无密码 |
| P03-C48 | 连续维护步骤与返回工作台 | “机构创建与接入 → 执行凭证 → 添加智能体 → 接入检查” | 普通机构创建或原请求成功回执确认后自动进入凭证步骤；开通/关联回执带入目标与 integration；各步骤展示真实完成事实和未执行项 | 可选步骤允许跳过；完成后返回目标工作台；只读检查只核对既有凭证与部署状态 | 授权、部署、凭证分别保留成功事实；跳过不标完成；检查不发模型、工具或外部消息请求 |
