# P09 模板新建与详情实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

元数据请求绑定[CreateAgentTemplateRequest](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/dto/request/CreateAgentTemplateRequest.java)、[UpdateAgentTemplateRequest](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/dto/request/UpdateAgentTemplateRequest.java)与[AgentTemplateAdminService](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/service/AgentTemplateAdminService.java)。创建名称必须非空白；现有 DTO 未定义名称等文本的业务最大长度，数据库存储限制不能冒充已完成字段校验。更新 category/description/icon_url 的 null 表示不更新，显式清空必须提交空字符串，tags 清空提交空数组。草稿原地更新，非草稿更新返回同 template_key 下新版本草稿；返回 ID 必须作为后续保存目标。

发布校验绑定[AgentTemplateService.validateDefinition](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/AgentTemplateService.java)：提示词、角色简介和可用 LLM 必填；基础能力必须是同定义匹配的公共已发布版本，一个定义只能挂一个版本。SKILL 激活模式必须与版本 descriptor.activation_mode 相同，token_budget 必须正数，不能把界面“留空”视为发布合法；TOOL 名称只读 descriptor.tool_name，须匹配执行器登记及 contentHash，不能从定义 key/handler 名猜测。资源/协作槽位 key 分别在所属集合唯一、匹配 `[a-z][a-z0-9_]{0,63}`，label 非空白；资源类型只允许 TOOL/WORKFLOW/KNOWLEDGE_SOURCE。运行覆盖的 null 表示继承，值域由[AgentExecutionConfig](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/runtimeconfig/AgentExecutionConfig.java)复用运营配置注册表；页面字段的限制与后端校验须逐项一致。

源码：[AgentTemplateDetailPage.vue](../../../frontend-platform/src/views/platform/AgentTemplateDetailPage.vue)、[api/index.ts](../../../frontend-platform/src/api/index.ts)。页面当前大量硬编码中文；模板定义接口为 `AgentTemplateDefinition`，运行预算和动态数组字段由 DTO 给出，但名称/分类/描述等长度、唯一性、后端校验来源未见。
