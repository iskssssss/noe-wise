# P05 模型费用账单控件合同

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文。模型费用只读调用时已保存的模型价格和原用量账本，不提供独立售价、商业账单草稿、封账、补充销售单或销售调账。计量、精度和缺口定义归[用量与账单设计](../../02-架构与设计/14-用量与账单设计.md)；实现和验收证据由[验收索引](../../08-数据与工具/ui-acceptance-index.json)记录，本文不宣称已验收。

直接来源：[平台模型账单](../../../frontend-platform/src/views/platform/BillingPage.vue)、[机构账单记录](../../../frontend-admin/src/views/admin/BillingRecordsPage.vue)、[共享费用明细](../../../frontend-shared/src/components/ModelBillingDetails.vue)、[类型](../../../frontend-shared/src/types/billing.ts)、[月度查询服务](../../../backend-java/skillforge-core-billing/src/main/java/com/skillforge/core/billing/application/ModelBillingService.java)、[响应合同](../../../backend-java/skillforge-core-billing/src/main/java/com/skillforge/core/billing/dto/billing/ModelBillingContracts.java)和[平台查询入口](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/PlatformModelBillingController.java)。控件和普通反馈遵循共享组件及顶部 Message 规则，不另设平行反馈机制。

| 子ID | 控件与数据绑定 | 行为、状态与失败恢复 | 验收断言 |
|---|---|---|---|
| P05-C33 | 页面标题、说明及只读边界 | 标题表达模型费用；说明费用来自调用时模型价格，查询不修改记录 | 页面及快捷入口均无销售写操作；模型价格维护回到 P10，不在账单页发布 |
| P05-C34 | 平台机构选择 `EntitySelect`、`tenantId` | 远程机构选项与既有选择解析使用真实服务；机构端固定自身机构 | 无匹配、加载失败和无权访问分别呈现；机构用户不能通过参数切换机构 |
| P05-C35 | 月份 `month` | 使用 `YYYY-MM`，明确北京时间；服务端默认北京时间当前月 | 月界按月初含、下月月初不含；浏览器时区不改变所选月份 |
| P05-C36 | 查询按钮与表单提交 | 平台端首次选择机构且月份有效时自动查询；之后修改范围需点击查询。机构和月份合法且有 `foundation.billing.read` 才提交 GET；提交中显示加载 | 空机构或非法月份不发送；Enter 与按钮使用相同路径，无写请求 |
| P05-C37 | 已应用查询范围 `applied` 和未提交筛选提示 | 修改选择不冒充已加载结果；查询新范围时重置分页，迟到请求不能覆盖新范围 | 翻页仍使用已应用机构和月份；提示清楚标出选择尚未生效 |
| P05-C38 | 加载、首次提示与空明细 | 初次未选范围提示先选择；读取中骨架；成功无记录显示本月无模型调用费用明细 | 查询失败不能显示为零消费；已有范围和新范围不混显 |
| P05-C39 | 错误反馈和“重试当前查询” | 使用共享错误消息；保留已应用范围，重试只重读原 GET | 错误不丢失筛选，不触发生成、封账或其他写动作 |
| P05-C40 | 月度摘要 `model_calls` | 展示当前月原模型调用数，包含未终结待核实调用，排除明确未发送媒体事实 | 不把工具执行次数或请求根当模型调用；累计报告与终态不重复计数 |
| P05-C41 | `known_amount`、`total_amount`、`missing_cost_count` | 金额单位元、精确字符串；总额为空显示待核实，另列已计算部分与缺口 | 缺价、缺用量、缺汇率不能变成零；已计算部分不标成完整费用 |
| P05-C42 | 输入/输出 Token 摘要 | 绑定 `prompt_tokens` / `completion_tokens`，空值显示待核实 | 不从字符、总量或缺失方向补造 Token；不以浮点格式化破坏大整数 |
| P05-C43 | 模型费用表与发生时间 | `row-key=id`；展示事件类型、供应商、模型和原 `occurred_at` | 明细身份稳定；读取无数据与读取失败可辨；长模型名和标识不丢失 |
| P05-C44 | 明细用量 | 调用、输入/输出 Token、图片、视频、字符与秒数仅展示真实非空字段 | 0 与空值可辨；媒体数量和十进制秒数保留字符串精度，不用请求数量补量 |
| P05-C45 | 原币及 CNY 费用 | 展示 `original_amount` / `original_currency` 和换算后 `amount`；金额为空保持待核实 | 不跨币种直接相加，不用当前汇率重算历史，不将 `priced` 文案解释为已支付 |
| P05-C46 | 费用依据展开区 | 展示原事件、Invocation/Attempt、Run/Session、价格快照、媒体模型 ID 和修订 | 无依据时显示缺口；不能用当前模型修订填历史；键盘可展开且无正文凭据 |
| P05-C47 | 服务端分页 `page/page_size/total` | 平台页选择20/50/100条，服务端上限200；查询新范围回第一页 | 页码与响应一致；加载中防重复翻页，分页不触发独立费用落账 |
| P05-C48 | 权限变化与范围清理 | 两端均检查当前 `foundation.billing.read`；失权清除已显示月度数据 | 前端隐藏不代替后端拒绝；旧请求返回后不能恢复已撤销范围的数据 |

## 已撤销控件编号

原 P05-C01 至 P05-C32（含字母后缀）以及 P05.UI01 至 P05.UI22 对应旧销售定价、商业账单和写入流程，已撤销且不复用。验收索引将这些编号标为 retired 并保留既有证据用于规则追溯；不再作为当前页面目标，也不代表保留旧销售业务数据。新的只读合同从 P05-C33 和 P05.UI23 起编号。
