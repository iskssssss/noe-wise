# P07 工作流审核实际控件合同

本表依据 [ReviewPage.vue](../../../frontend-platform/src/views/platform/ReviewPage.vue) 描述当前页面；保留编号供验收索引使用。审核请求使用列表记录的 id 与 updated_at，实际权限和安全扫描以服务端为准。

| 子ID | 控件或行为 | 当前实现 |
|---|---|---|
| P07-C01 | 页面 | 标题“市场审核”；当前页头无独立刷新按钮。 |
| P07-C02 | 状态筛选 | 下拉选择 pending、approved、rejected，默认 pending；查询后生效，不使用页签或 URL query。 |
| P07-C03 | 搜索 | 输入工作流名称，查询后应用。 |
| P07-C04 | 查询与重置 | 查询将当前条件应用并回第一页；重置搜索并恢复 pending。 |
| P07-C05 | 反馈 | 列表或动作错误由 FeedbackNotice 展示；成功后消息提示并刷新列表。 |
| P07-C06 | 未知结果 | 当前无专用未知结果队列或查证按钮。 |
| P07-C07 | 工作流名称 | 点击名称打开审核详情抽屉。 |
| P07-C08 | 列表字段 | 展示工作流名称、作者、版本、状态、审核说明；不显示独立 ID 或提交时间列。 |
| P07-C09 | 状态 | 使用 statusLabel 展示状态。 |
| P07-C10 | 操作 | 行按钮根据状态显示“查看并审核”或“查看记录”，打开抽屉；没有更多菜单。 |
| P07-C11 | 批准 | pending 且内容就绪时，具有 foundation.marketplace.publish 权限的用户可确认批准，以 id 和 updated_at 提交。 |
| P07-C12 | 抽屉关闭 | 展示选中工作流、版本、作者、状态及所见修订；拒绝理由非空时关闭保护。 |
| P07-C13 | 拒绝理由 | pending 时显示文本域，最长 1000 字符；提交拒绝前校验去除首尾空白后的内容非空。 |
| P07-C14 | 拒绝 | 具备 foundation.marketplace.update 且内容就绪时，以 id、updated_at 和理由提交，成功关闭抽屉并刷新列表。 |
| P07-C15 | 结果与刷新 | 成功后关闭抽屉、提示并读取列表；当前没有旧规格描述的未知结果队列和本地行乐观更新。 |
| P07-C16 | 详情内容 | 读取指定修订包文件，并校验 workflow_id、updated_at、version；提供文件查看与安装、权限、工具、连接器声明。 |
| P07-C17 | 列表与详情加载 | 列表有加载、错误、空态；详情失败可重试本修订或关闭后刷新列表。 |
| P07-C18 | 内容与权限边界 | 缺少可读取的 workflow.yaml 时禁止审核；批准和拒绝分别检查 publish 与 update 权限。 |

## 待验证场景

以下为验收要求，不表示当前实现已满足或已经执行：验证不同审核权限的入口与服务端拒绝、修订过期时的冲突处理、拒绝理由的空白和长度校验，以及读取失败后的重试。写入成功后刷新失败应保留已知结果；网络中断等结果未知时应先核对原操作结果，不因页面提示或刷新失败重复提交审核。
