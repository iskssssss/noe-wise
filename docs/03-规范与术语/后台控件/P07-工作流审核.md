# P07 工作流审核实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

源码：[ReviewPage.vue](../../../frontend-platform/src/views/platform/ReviewPage.vue)、[api/index.ts](../../../frontend-platform/src/api/index.ts)。审核 API 读列表带 status/search/page/limit，写入以 review `id` 和 `updated_at` 提交。

| 子ID | 真实控件与绑定 | 外观/文案（历史 key） | 数据、可见/可用条件 | 动作、状态与失败恢复 | 验收断言 |
|---|---|---|---|---|---|
| P07-C01 | 页面标题和刷新按钮 | `platform.review.title`、`common.action.refresh`；刷新位于页头 actions | loading 时刷新禁用 | 调 `load`；错误可通过表格 retry | 标题、刷新与路由一致，刷新不丢 query |
| P07-C02 | 审核页签 | 全部用 `platform.enums.reviewStatus.pending/all/approved/rejected`（all 使用 `platform.common.status.all`）；status 默认 pending | status 仅四值，query 非法回 pending | 切换路由并回第一页；load 使用已提交 status | 初次 `/platform/review` 请求 pending；页签切换不混显示上一队列 |
| P07-C03 | 搜索输入 | aria/placeholder `platform.uiReview.search` | `search` 草拟、`appliedSearch` 已提交，服务端按 workflow/name/id 搜索 | Enter 非 composing 执行 query；清空后查询 | 未点击查询列表不变；query URL 和请求 search 一致 |
| P07-C04 | 查询和重置按钮 | `platform.common.actions.query`、`common.action.reset` | loading 禁用 | query trim 并 page=1；reset status=pending、search 清空 | 重置不会保留旧 status/search；重复点击不产生无意义请求 |
| P07-C05 | 结果/反馈提示 | `ElAlert` 内容反馈 `platform.review.approved/rejected/savedRefreshFailed/unknown/conflict/confirmed` | `feedback` 非空；审核成功和刷新失败分开 | 信息提示；失败保留行和理由输入 | 成功写入后 refresh 失败不显示审核失败；unknown 不自动重放 |
| P07-C06 | 不确定结果队列 | 当前 workflow 名 + `platform.uiReview.unknown`，按钮 `.verify` | `uncertain` Map 以 review id 存储 | verify 以 all + search id 查询；仍未知则保留条目 | 超时/5xx 后对象进入待查；查证状态变化才清除，查证失败不清空本地状态 |
| P07-C07 | 表格工作流名称列 | `platform.review.workflowName`；单元格是 ghost Button | `workflow_name`，row key `id` | 点击打开 detail drawer，不触发行导航 | 长名称可查看全文；相同名称不同 id 行不混淆 |
| P07-C08 | 表格 ID、版本、作者、提交时间列 | `platform.uiReview.id/version/author/revisionTime`；时间为 `revision_at` | `MarketplaceReview.id/version/author/revision_at` | 只读；提交时间不是 created_at | 每列与 DTO 绑定；未知值不冒充提交人/当前账号；时间格式一致 |
| P07-C09 | 表格状态列 | 表头 `platform.common.table.status`；`ElTag` 文案 `platform.enums.reviewStatus.*` | row.status | 只读；pending warning，approved success，rejected danger | 状态 tag 与筛选队列一致，非 pending 行无通过/驳回写入口 |
| P07-C10 | 行操作列和更多菜单 | 表头 `.operation`；更多按钮 aria `platform.uiReview.actions({name})`，文案 `.more`；菜单 `.detail/.approve/.reject` | pending 才显示写菜单；busy/uncertain 禁用 | detail 打开详情；approve/reject 调对应动作 | 直接通过按钮和菜单资格一致；刷新/重排后仍用 row.id |
| P07-C11 | 通过按钮和确认框 | 按钮 `.approve`；确认标题 `.approveTitle`、正文 `.approveConfirm` | 仅 pending 且不 busy/uncertain | 快照整行，先确认，再以 id+updated_at approve；失败保留行 | 确认取消无写；确认期间 row 更新时按快照/冲突处理；按钮防连点 |
| P07-C12 | 驳回抽屉标题、目标摘要和取消 | 标题 `platform.review.rejectTitle`，description workflow name；摘要 id/version；取消 `common.action.cancel` | `rejectTarget`，打开不发请求 | 关闭走 workspace guard；脏理由取消需确认 | Esc/关闭/取消保护理由；取消后队列原状态不变 |
| P07-C13 | 驳回理由文本域 | label `platform.uiReview.reason`，required；错误 `.reasonInvalid` 或服务端错误；maxlength=1000 | `reason` trim；1–1000 字符规则由 UI 明确，后端仍需一致 | 空/超长不发请求并定位；提交失败保留理由 | 中文输入法 composing 不误提交；全空白被拒；错误映射到该文本域 |
| P07-C14 | 驳回确认按钮 | 文案 `platform.review.reject`；busy/uncertain 禁用，loading 显示 | 目标 id+updated_at，理由文本 | reject 写请求；成功关闭抽屉、更新行、刷新；冲突提示 | 同一行不重复提交；只锁目标行；拒绝成功不会因刷新失败再次驳回 |
| P07-C15 | 审核结果写入与刷新 | Toast `platform.review.approved/rejected`，刷新失败 `.savedRefreshFailed` | `items` 先局部更新，再 `load` | 4xx/409 显示错误；网络/5xx 进 unknown 并 verify | 已成功对象仍显示结果；服务端刷新失败保留本地成功事实 |
| P07-C16 | 审核详情抽屉 | 标题 `.detail`、description workflow name；字段 id/version/revisionTime/reviewer/reviewedAt/reason | `detail` 是点击时 row；`revisionTime` 当前绑定 `updated_at`，需确认是否应为 `revision_at` | 关闭只清 detail；只读 | 不把 `updated_at` 冒充模板修订时间，事实差异在契约中修正；reason 空显示破折号 |
| P07-C17 | 表格空态、加载和错误 | `platform.review.emptyState`、`.loadFailed`；`Vben VXE Grid` retry | `usePagedList` loading/error/total | 重试只读当前 status/search/page | 真空队列显示空态；加载失败不是空队列；返回范围由 total/pageSize 真实表达 |
| P07-C18 | 当前实现缺口：提交信息与完整审核权限 | 表格显示 author/revision_at，但没有独立 submitter 字段；源码未绑定权限代码 | 具体 reviewer/review permission 未在前端来源给出 | 不新增权限或“安全扫描”字段；目标需补契约 | 验收不得把 author 解释为提交人或当前审核人；仅验证实际 DTO 字段 |
