## 待验证场景

以下为验收要求，不表示当前实现已满足或已经执行：验证创建、更新和发布的权限及服务端拒绝；编辑时核对目标部署与修订，冲突不得覆盖草稿；保存或发布结果未知时核对原回执，不能重复派发。还需检查筛选、空态、读取失败与重试，以及成功写入后列表刷新失败时的结果提示。

## 后端契约绑定与未绑定项

- 平台工具部署接口由 [PlatformAgentToolController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/PlatformAgentToolController.java) 提供；读取、创建、更新和发布分别要求 `foundation.system_agent_tools` 下的对应权限，实际路由前缀为 /api/v1/admin/system-agent-tools。
- 写入对象 DeploymentWrite 的字段为 name、toolDefinitionId、providerType、providerRef、environment、active，定义和公共资源校验见 [PlatformAgentResources.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/PlatformAgentResources.java)。发布时从工具定义解析当前发布版本；写入请求不直接选择工具版本。
- 后端写入会对 name、providerRef 做非空校验，toolDefinitionId 必须为正整数，providerType 严格为 PLATFORM，environment 严格为 TEST 或 PRODUCTION。校验要求工具具有当前发布版本，providerRef 对应同名已注册的平台工具。
- 创建产生草稿；更新和发布携带正整数 expected_revision，创建、更新和发布使用请求身份并可查询回执。后端允许管理写入 active=false，但资源解析会拒绝停用部署，因此停用记录不能被当作可执行部署。
- 环境门禁在资源用于执行时生效：调试只允许 TEST，发布或普通执行只允许 PRODUCTION；草稿挂载校验不提前执行该环境门禁。版本归属、provider 和环境规则的执行点见 [PlatformAgentResources.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/PlatformAgentResources.java)。
- 页面控件与结果未知时的核验入口见上表；不能把不存在的复制按钮或手填 providerRef 描述为当前页面能力。
