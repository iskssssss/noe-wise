# P13 平台工具部署实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

## 后端契约绑定与未绑定项

- 平台工具部署接口由 [PlatformAgentToolController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/PlatformAgentToolController.java) 提供，并受类级 @RequireRole(PLATFORM_ADMIN) 保护；实际路由前缀为 /api/v1/admin/system-agent-tools。
- 写入对象 DeploymentWrite 的字段为 name、toolVersionId、providerType、providerRef、environment、active，定义和公共资源校验见 [PlatformAgentResources.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/PlatformAgentResources.java)。
- 后端写入会对 name、providerRef 做 required/trim 后的非空校验，toolVersionId 必须为正整数，providerType 严格为 PLATFORM，environment 严格为 TEST 或 PRODUCTION，active 必须是布尔值；后端源码未定义 name 或 providerRef 的长度上限。
- 页面当前对 name 的 128 字符限制和 providerRef 的 255 字符限制属于前端校验值，不是后端契约；页面不得把这两个数值描述成服务端上限。后端仍会校验工具版本是公共且已发布的 TOOL 版本，并校验 providerRef 能解析为同名已注册的平台工具。
- 创建从 revision 1 开始；更新必须携带正整数 expected_revision，使用 CAS 成功后 revision 加一。后端允许管理写入 active=false，但资源解析会拒绝停用部署，因此停用记录不能被当作可执行部署。
- 环境门禁在资源用于执行时生效：调试只允许 TEST，发布或普通执行只允许 PRODUCTION；草稿挂载校验不提前执行该环境门禁。版本归属、provider 和环境规则的执行点见 [PlatformAgentResources.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/PlatformAgentResources.java)。
- 抽屉宽度、生产确认、复制按钮、未知网络结果核验和前端 128/255 字符提示是页面行为；后端只保证上述字段校验、版本/provider 绑定、环境约束和 revision 冲突语义。
