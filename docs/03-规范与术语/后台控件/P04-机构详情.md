# P04 机构工作台详情控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

当前源码为[平台机构工作台](../../../frontend-platform/src/views/platform/InstitutionWorkspacePage.vue)、[机构端工作台](../../../frontend-admin/src/views/admin/InstitutionWorkspacePage.vue)、[共享工作台展示](../../../frontend-shared/src/institution/InstitutionWorkspace.vue)、[机构设置面板](../../../frontend-platform/src/views/platform/TenantSettingsPanel.vue)及[平台 API](../../../frontend-platform/src/api/index.ts)；[TenantManagePage.vue](../../../frontend-platform/src/views/platform/TenantManagePage.vue) 保留正式详情入口并组合工作台。机构目录合同见 [P03](P03-机构管理.md)。平台详情读写继续使用 `GET /admin/tenants/detail?tenantId=` 与 `PATCH /admin/tenants/update`，成员使用 `/admin/tenants/members*`，不新增业务写 API。

后端直接调用链为[PlatformTenantController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/PlatformTenantController.java)、[PlatformTenantAccountService.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/service/PlatformTenantAccountService.java)、[UpdateTenantRequest.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/dto/tenant/UpdateTenantRequest.java)、[CreateTenantMemberRequest.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/dto/tenant/CreateTenantMemberRequest.java)、[UpdateTenantMemberRequest.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/dto/tenant/UpdateTenantMemberRequest.java)、[ResetPasswordRequest.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/dto/tenant/ResetPasswordRequest.java) 及[基线迁移 V1](../../../backend-java/skillforge-migration/src/main/resources/db/migration/V1__baseline.sql)。历史表中的旧字段范围与旧交互不自动成为当前接口契约，当前表单只暴露正式 DTO 支持的字段。
