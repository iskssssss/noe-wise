通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

## 后端契约绑定与未绑定项

- 详情页及其所有写入动作受 [SystemAgentController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/SystemAgentController.java) 的 @RequireRole(PLATFORM_ADMIN) 保护；实际路由为 /api/v1/admin/system-agents。详情、版本、运行记录、挂载选项和所有状态/保存/调试请求均属于平台管理员接口。
- 配置对象的后端字段是 name、description、systemPrompt、modelConfigId、timeoutSeconds、maxSteps、mounts，类型和挂载对象定义见 [SystemAgentTypes.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/SystemAgentTypes.java)。名称非空且最多 128 个字符，描述非空时最多 2000 个字符，systemPrompt 不得为 null 且最多 64000 个字符，timeoutSeconds 范围为 1–3600，maxSteps 范围为 1–100；草稿可暂不填写模型和非空提示词，发布或执行时两者都必须存在且模型必须是启用的 LLM。
- MODEL_TASK 必须始终没有挂载且 maxSteps=1；AGENT_RUN 才能维护能力挂载。保存草稿时只做草稿资源校验，发布/执行时才校验部署环境和可执行配置。
- 每个挂载的 capabilityType 严格为 SKILL 或 TOOL，capabilityVersionId 必须为正整数且必须指向平台已发布的能力版本，同一类型与版本不得重复。SKILL 必须提供正整数 tokenBudget 和 activationMode=ALWAYS|ON_DEMAND，不得带 toolDeploymentId；TOOL 必须提供正整数 toolDeploymentId，不得带 tokenBudget 或 activationMode，且部署的工具版本必须与挂载版本一致。规则实现见 [PlatformAgentResources.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/PlatformAgentResources.java)。
- 发布或普通执行只接受 PRODUCTION 工具部署，调试执行只接受 TEST 工具部署；部署必须为 PLATFORM provider，且 provider_ref 必须匹配已注册的平台工具。停用部署会在执行资源解析时被拒绝；草稿保存不提前执行环境门禁。
- 发布、停用、启用、归档、保存和调试均以当前 revision 做 CAS；发布递增发布版本，停用只允许从 published 进入 disabled，启用只允许从带发布配置的 disabled 恢复，已发布状态必须先停用再归档。删除还受草稿、无用途、无发布版本和无运行记录约束。
- 调试请求的 source 只能是 DRAFT 或 PUBLISHED；控制器要求 agent_id、source、input、idempotency_key 非空及正整数 expected_revision，服务端还要求输入非空且最多 128000 个字符。幂等键按租户与智能体运行记录去重。离开页面后，可在调试页使用原操作标识通过 `GET /admin/system-agents/debug-result?agentId=…&idempotencyKey=…` 只读查询内部调试记录；查询不到不证明原请求未受理，也不解除未知状态。读取记录不会派发或恢复执行；`system_agent_outcome_unknown` 保持结果未知。
- 页面展示的 null 占位、调试来源禁用态、运行轮询和输入框即时校验属于前端行为；后端不承诺页面文案、轮询间隔或前端组件的 null 选项。尤其是挂载行可暂存的 null 值，提交时必须服从上述按能力类型的后端规则。
