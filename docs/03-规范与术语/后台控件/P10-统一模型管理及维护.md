# P10 统一模型管理及维护实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

字段后端事实绑定[ModelWrite](../../../backend-java/skillforge-core-model/src/main/java/com/skillforge/core/model/ModelWrite.java)、[PlatformModelCatalogService.validate/text/positive](../../../backend-java/skillforge-core-model/src/main/java/com/skillforge/core/model/PlatformModelCatalogService.java)与[平台模型入口](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/PlatformModelController.java)。该入口统一要求 `platform_admin`；更新及回滚使用 `expected_revision`，冲突返回409；回滚追加修订，不覆盖历史。

下表中的文本上限按 Java `String.length()` 即 UTF-16 代码单元计算；后端先对原串检查非空白和长度，再 trim。名称上限200、模型标识256、服务地址2048、非LLM提供方64、新凭据16384。服务地址仅 http/https、有 host、无 user-info/query/fragment。超时为1–600秒，三个 Token 容量字段为1–2147483647整数且输出上限不得超过支持上限、必须小于上下文窗口；temperature 可空，非空必须有限且在0–2内，后端未要求0.1步长。Embedding dimensions 为1–65536；Rerank path 必须以单斜线起始，不能包含 `?`、`#` 或 `..`。这些约束须分别接到对应字段和错误位置，现有前端未完全接线不能标通过。

凭据留空仅在旧记录存在且 endpoint/provider/service/authentication 范围不变时保留原值，变化时必须重填；新填凭据按上述 text 规则 trim。安全投影[ModelView](../../../backend-java/skillforge-core-model/src/main/java/com/skillforge/core/model/ModelView.java)只返回 `credential_configured`，没有明文或密文。成本单价的领域值为可空非负 `BigDecimal`（小数分），最多六位小数，上限 `9223372036854775807`；JSON 使用十进制字符串或 null，不接受数值、负数、前导零或指数表示。币种为 Java Currency 支持值，只有 null 缺省为 CNY，空串及未知币种拒绝。前端使用文本输入和 `string|null` 接口，不经过 JavaScript Number；精确单位及费用来源见[用量与账单设计](../../02-架构与设计/14-用量与账单设计.md)。

四类媒体使用独立 `media_pricing`；未配置时整体为 null，选择单位后须填写对应单价，明确零价可用。图片按输出张或 Token；视频按输出个数、视频秒或 Token；识别按输入音频秒或 Token；合成按计费字符、输出音频秒或 Token。Token 价格要求输入、输出双价，视频秒价还须填写适用分辨率。切换单位清除不适用价格与条件，清空单位恢复整体缺价；加载、保存和未保存探测使用同一结构，媒体请求中的三种通用价格均为 null。修改价格不要求重新输入连接范围未变的已保存凭据。

LLM 的 `cache_pricing` 可选择总输入统一价、缓存命中分价或命中与写入分价；整体 null 表示统一价。单价均为原币分/百万 Token，空值保留未知，字符串零价可用；写入单价表示该部分输入的完整价格。切回统一价清空整个结构，切到仅命中分价清空写入单价，切换非 LLM 类型清空缓存结构。已保存加载、未保存测试和保存使用同一字段结构，修改缓存价格不改变已存凭据的复用条件。缺少供应商报告的必要缓存数量时费用继续待核实，页面不套用固定品牌折扣。

## 国内模型与多媒体扩展控件

本节定义国内模型能力的控件目标。服务类型、型号、协议和权限决定实际可配置能力；实现需分别验证前端参数、代理/网关、平台 API 与供应商请求。接口验证不覆盖布局、键盘或触控。

已冻结的 Qwen ASR 接线按 `bailian-cn-beijing-qwen-asr / qwen-asr-native` 精确选择，平台测试请求提供 `audio / language / enable_itn`，`audio` 为公开 HTTPS 或 MP3/WAV Data URI 字符串。平台辅助控件 `assetJobId / assetId` 先经当前账号认证下载已有音频产物，再由前端检查媒体类型和编码后长度、转换为 Data URI 填入 `audio`，辅助编号不作为转写 DTO 字段提交。Agent 的 `transcribe_audio` 另可引用同 Session 的 `job_id + asset_id`，由宿主核对归属、限量回读并转换为 Data URI。Paraformer 保留 URL 文件识别及自身参数，两类专属选项不得混用，也不按模型名前缀推定协议。局部测试、真实调用、文件覆盖及恢复后验证的范围统一见上述 Note，不从单项成功外推其他服务或浏览器行为。

模型测试应分别覆盖配置测试、凭据复用、音频输入续接、所有权隔离、匿名拒绝和模型数据不变性。TTS、ASR、视频、图片、向量与重排按具体服务和型号独立验收，记录回执、用量、费用与失败/UNKNOWN；接口通过不代表浏览器体验或供应商账单已经核实。测试账号和临时资源按授权范围清理，并记录实际清理结果。
