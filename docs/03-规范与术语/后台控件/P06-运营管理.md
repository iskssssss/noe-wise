# P06 运营管理实际控件合同

本表依据 [OperationsPage.vue](../../../frontend-platform/src/views/platform/OperationsPage.vue) 描述当前页面；编号保留以供验收索引使用，页面能力与验收结果应分别判断。

审计查询通过 `api.operations.auditLogs` 读取，账单扫描使用 `processBillingStates` 与 `billingStateResult`；权限和接口最终以服务端为准。

| 子ID | 控件或行为 | 当前实现 |
|---|---|---|
| P06-C01 | 页面 | AdminPage 标题“运维审计”，说明查看审计与执行账单扫描。 |
| P06-C02 | 区域 | 页面包含审计卡片和按权限显示的账单扫描折叠区，不使用页签或 tab 查询参数。 |
| P06-C03 | 操作类型 | 文本输入；查询后作为已应用条件。 |
| P06-C04 | 机构筛选 | 默认按权限选择机构或输入历史机构标识，可手动切换两种方式。 |
| P06-C05 | 查询与重置 | 查询将当前筛选复制到已应用条件并回第一页；重置清空条件并查询。 |
| P06-C06 | 筛选区域 | 各条件直接显示；当前没有高级筛选展开控件。 |
| P06-C07 | 操作者 | 输入操作者 ID，查询时传入已应用条件。 |
| P06-C08 | 资源类型 | 输入资源类型，查询时传入已应用条件。 |
| P06-C09 | 时间范围 | 日期时间范围控件按北京时间选择，转换为带偏移的时间值；查询后生效。 |
| P06-C10 | 筛选反馈 | 页面提示当前已应用范围以及未提交的修改；当前未单独实现旧规格中的筛选错误提示。 |
| P06-C11 | 审计列表 | ElTable 显示已应用条件的结果，失败时提供重试当前查询；服务端 total 用于分页。 |
| P06-C12 | 时间列 | 使用 formatDateTime 展示 created_at。 |
| P06-C13 | 操作列 | 显示 action 原文。 |
| P06-C14 | 操作者列 | 显示 actor_id。 |
| P06-C15 | 资源列 | 资源类型与资源 ID 分列展示。 |
| P06-C16 | 说明列 | 显示 message，长文本由表格溢出提示处理。 |
| P06-C17 | 详情入口 | 每行“查看”打开审计详情抽屉；没有旧的更多菜单。 |
| P06-C18 | 复制资源标识 | 当前页面没有复制资源标识按钮。 |
| P06-C19 | 详情抽屉 | 展示所选行的操作、Trace ID、说明和 payload。 |
| P06-C20 | 详情复制 | 当前抽屉没有复制资源标识按钮。 |
| P06-C21 | 详情说明 | 展示所选行 message。 |
| P06-C22 | 详情载荷 | 展示 trace_id 和 JSON 格式化的 payload；数据暴露边界以服务端响应为准。 |
| P06-C23 | 扫描说明 | 具有 foundation.billing.run 权限时显示账单扫描折叠区，说明未知结果可用同一操作键查询或重试。 |
| P06-C24 | 扫描与确认 | 点击扫描先确认；确认后生成或复用操作键，调用接口前再次检查 foundation.billing.run。 |
| P06-C25 | 操作键 | 首次确认后生成 UUID 并显示；操作键保留在页面内存中。 |
| P06-C26 | 执行中 | 扫描按钮显示任务忙碌状态，不提供百分比或进度。 |
| P06-C27 | 扫描错误 | 错误显示在页面反馈中；操作键保留，可查询或使用同一键重试，不区分明确拒绝与未知结果的专门状态。 |
| P06-C28 | 查询回执 | 存在操作键时显示查询回执；无回执提示结果仍未确认。 |
| P06-C29 | 同键重试 | 已有操作键且无回执时按钮显示“使用同一操作键重试”；再次确认后复用原键。 |
| P06-C30 | 扫描结果 | 展示 scanned、warning、active 和 completed_at；操作键显示在扫描操作区。 |
| P06-C31 | 离开页面 | 当前操作键保存在组件内，页面未提供旧规格所述的扫描在途离开保护或跨刷新恢复。 |
| P06-C32 | 权限与新建扫描 | 扫描区域及按钮按 foundation.billing.run 授权；出现回执后“新建扫描”清除键和回执。 |

## 待验证场景

以下为验收要求，不表示已实现或已执行：核对筛选条件、分页请求和结果范围一致，区分读取失败与空列表；日志中的时间、操作者、资源及详情只展示服务端实际返回值，特殊字符按文本处理。验证无权限时读取与操作边界、重复确认及结果未知时的原操作键和回执处理；无回执不能当成成功或确定失败，扫描结果不得虚构进度或统计范围。页面销毁后操作键的恢复能力另行验收。
