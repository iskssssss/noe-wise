# P06 运营管理实际控件合同

通用组件 API 以 [Vben Admin](https://doc.vben.pro/) 与 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准；本文只约束业务字段、状态和验收编号。

通用组件及交互采用 Vben v5.7.0 / Element Plus；本文保留业务字段、权限、精度和数据保护验收编号。源码引用用于定位业务归属，页面外观和操作体验由人工验收，不把历史实现细节作为实现契约。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

审计读取 API 为 `api.operations.auditLogs({ action, tenant_id, actor_id, resource_type, from, to, page, limit })`，实际 query 映射为 `action/tenantId/actorId/resourceType/from/to/page/limit`；账单扫描使用 `processBillingStates(operationId)` 与 `billingStateResult(operationId)`，回执类型为 `{ operation_id, scanned, warning, active, completed_at }`。
