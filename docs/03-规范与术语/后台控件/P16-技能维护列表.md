# P16 技能维护列表实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

平台技能列表是独立 `/platform/skills` 页面，通过 `/api/v1/admin/capabilities/skills/catalog` 一次读取 SKILL 专用摘要，在完整返回集合上搜索，不再逐行读取完整版本；当前直接展示过滤结果，分页仍是未接入的目标，见 P16-C03e/C11。页面通过 `POST /api/v1/admin/capabilities/skill-drafts/create-with-receipt` 提交请求号与 metadata，原子创建平台 SKILL 定义、空工作草稿和创建回执；机构端使用对应非 admin 前缀。原 C08/C09/C10 和 X30 编号保留追溯，原“定义成功、草稿失败后补创建”的两阶段要求由本次原子合同取代。本文其他历史控件目标不因此视为已实施或已验收。
