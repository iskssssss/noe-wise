# P32 日志与运维逐控件规格

共同合同见[P26–P32](../06-后台逐控件规格.md#基础页面共同原子合同)，状态/证据归[验收索引](../../08-数据与工具/ui-acceptance-index.json)。入口为 `/platform/foundation/operations`、`/admin/foundation/operations`；页面来源为 [OperationsPage.vue](../../../frontend-shared/src/foundation/operations/OperationsPage.vue)，类型及CSV下载见 [contracts.ts](../../../frontend-shared/src/foundation/operations/contracts.ts)，API根为宿主 `foundation/operations`。

权威合同为 [FoundationAuditService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/operations/FoundationAuditService.java)、[FoundationRetentionService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/operations/FoundationRetentionService.java)、[FoundationOperationsStatus](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/operations/FoundationOperationsStatus.java) 和 [OperationsContracts](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/operations/OperationsContracts.java)。平台/机构范围由真实Subject决定；审计只暴露脱敏元数据。到期清理只操作服务器冻结候选，执行时再次检查调查引用保护，事务失败回滚且保留失败回执。运维状态是当前宿主JVM/连接池/依赖采样，不证明业务功能已验收。

## 稳定对象合同

| 编号 | 对象与文案/组件 | 数据、触发与权限 | 状态、异常与恢复 | 具体验收断言 |
| --- | --- | --- | --- | --- |
| P32-C01 | 标题/说明及无权限告警 | “安全审计与运维”；“检索安全事件…真实采样”；无tabs明确无权 | 无权不加载隐藏区域，不显示伪健康 | 入口与真实动作权限一致 |
| P32-C02 | 安全审计/保留清理/运维状态页签 | 分别operations.audit_read/retention_read/status_read | 当前页签按实时权限过滤；切换使旧请求世代失效 | 只审计读无清理/采样数据；旧回包不写入新身份 |
| P32-C03 | 写错误/本地校验/结果反馈 | ElAlert；task.error/validation/feedbackType | error/warning/success按真实结果，失败回执不显示成功 | Toast消失仍有错误；写成功后读失败不重发 |
| P32-C04 | 动作编码筛选 | filters.action:string，例auth.login；空不提交 | 草拟值只在检索时应用；clearable | 修改未查询再导出仍用已应用条件 |
| P32-C05 | 操作者ID筛选 | filters.actor_id:string | 字符串精度保留，空不提交 | 大ID不转number；真实范围仍服务端过滤 |
| P32-C06 | 分类筛选 | authentication/authorization/sensitive/export/operation | 可清空；不编造额外类别 | 每枚举请求/返回分类一致 |
| P32-C07 | 结果筛选 | success/failure/denied | 可清空；拒绝与失败分开 | denied不会显示为普通成功 |
| P32-C08 | 资源类型筛选 | filters.resource_type:string | 空不提交；不是可执行表名 | 查询不执行客户端SQL/代码 |
| P32-C09 | 追踪ID筛选 | filters.trace_id:string | 绑定已应用快照 | 值不截断、返回trace可定位同事件 |
| P32-C10 | 开始/截止时间字段实例 | from/to原生datetime-local，提交转换ISO绝对时刻；from<to | 非法时间就地拒绝；不发送NaN/错误时区；两个字段独立定位 | 浏览器本地时间与服务器范围一致，截止不晚拒绝 |
| P32-C11 | 检索按钮 | 生成applied快照、page=1；GET audit/summaries?page&page_size=50 | loading独立；旧数据刷新与失败分开 | 翻页沿applied，快速A/B只显示B，空条件不限制无关字段 |
| P32-C12 | 导出当前范围按钮 | audit_export；POST audit/export，body=applied；Blob名security-audit.csv | 防重；identity变化不交付旧下载；对象URL释放 | 导出是已应用条件及当前范围，CSV不泄露秘密，不下载错误JSON |
| P32-C13 | 审计读取错误/列表/空态 | AuditSummaryPage.items/total；九字段目录不含payload；row-key=id；空态“当前范围没有审计事件” | 成功空与失败分开；保存筛选/页号 | 跨租户事件不可见，不将失败total变0冒充空；与完整审计查询共享读取批次 |
| P32-C14 | 审计ID列 | id:string | 只读，精度保留 | 与保护登记真实audit_id一致 |
| P32-C15 | 操作者列 | actor_id:string|null | null保持缺失，非当前用户自动代入 | 背景事件无actor不伪造成员 |
| P32-C16 | 动作列 | action稳定code | 纯文本 | 真实操作与审计一致 |
| P32-C17 | 分类列 | category | auth/授权/敏感/导出/操作分类事实 | 与筛选请求匹配 |
| P32-C18 | 结果列 | outcome | success/failure/denied不同事实 | 权限拒绝未执行副作用仍可识别 |
| P32-C19 | 资源列 | resource_type:string|null | 不从payload推断资源 | 缺资源不构造SQL对象 |
| P32-C20 | 说明列 | message:string|null | 公开脱敏，长文可到达 | 密码/token/MFA种子/正文秘密不进入DOM/CSV |
| P32-C21 | 追踪ID列 | trace_id:string|null | 字符串不取整或截断 | 同trace关联事实可追溯 |
| P32-C22 | 时间列 | created_at，formatDateTime | 服务端绝对时刻 | 排序/时区与权威查询一致 |
| P32-C23 | 审计分页 | 1起page、固定50、真实total | 不提供伪可变size；沿applied查询；末页必要修正 | 翻页不采用尚未查询的filters，total不是当前数组长度 |
| P32-C24 | 保留读取错误与策略表单 | 并读GET retention/runs/holds；同视图世代更新policy | 无错误时显示权威策略；失败不套初始默认假装生效 | 当前tenant/平台隔离，旧回包不覆盖新政策 |
| P32-C25 | 审计保留天数 | retention_days整数30–3650；retention_manage才可编辑 | policy.version来自服务器；初始180不自证生效 | 30/3650边界、非整数拒绝；无权只读 |
| P32-C26 | 允许到期清理开关 | enabled:boolean；retention_manage | true不立即执行删除；默认关闭取真实策略 | 仅改开关无副作用，服务器启用后才允许preview |
| P32-C27 | 保存策略按钮 | PUT retention{retention_days,enabled,expected_version} | busy防重；完整CAS，成功使旧preview失效 | 冲突不覆盖别人政策，不在客户端改cutoff绕过 |
| P32-C28 | 生成清理预览按钮 | retention_execute且policy.enabled；POST retention/preview | 服务器冻结候选与保护计数，返回preview.id | 预览零实际删除，不以本地列表构造候选 |
| P32-C29 | 预览提示 | id/candidates/protected_count/status；ElAlert | ready/succeeded/failed/expired映射；0合法 | 数量与冻结回执一致，过期不当ready执行 |
| P32-C30 | 执行本次预览按钮与确认 | ready+retention_execute；POST retention/execute{id} | 确认冻结候选/受保护数；执行再次检查保护；失败/超时不自动重发 | 确认取消无删除；新增保护被保留；同预览回执可查，无跨域执行 |
| P32-C31 | 执行结果反馈 | 根据回执status选择success/error/warning，显示实际deleted_count | failed明确“失败且已回滚”；不是候选数量即已删除 | 注入失败业务删除为0且回执failed，未知先查回执 |
| P32-C32 | 执行回执表与回执ID列 | retention.runs，row-key=id:string | 成功空表与读失败分开 | 只显示当前作用域回执，ID保持精度 |
| P32-C33 | 回执候选/受保护/实际删除列实例 | candidates/protected_count/deleted_count三字段，0有效 | 冻结候选与实际删除不是同一数量 | 三列分别核对保护变化、成功和回滚，不用候选数伪删除数 |
| P32-C34 | 回执状态列 | ready/succeeded/failed/expired业务文案 | 失败/过期非成功 | 状态与真实事务结果一致 |
| P32-C35 | 回执失败原因列 | failure_code:string|null | 公开原因，不含SQL秘密或正文 | failed保留可读原因，成功不伪造错误 |
| P32-C36 | 回执登记时间列 | created_at，formatDateTime | 服务端时刻 | 重新执行同回执不伪造新登记时间 |
| P32-C37 | 调查保护审计ID输入 | retention_manage；holdForm.audit_id字符串，required | 真实同域审计；从列表选同一ID保留草稿，已编辑后选其他ID须确认放弃 | 大ID精度保持，外域/不存在拒绝；取消切换保留原ID、依据和到期时间 |
| P32-C38 | 调查或法务依据输入 | reason必填、最多500；纯文本 | 错误保留；已编辑草稿纳入离页保护；禁止秘密依据正文进入元数据 | 空白/超长拒绝，引用标识可追溯；仅自动带入ID不算未保存编辑 |
| P32-C39 | 可选保护到期时间输入 | expires_at datetime-local；空提交null显式保留，非空转ISO | 非法时间就地拒绝 | null与有期限不同，时区不偏移 |
| P32-C40 | 登记保护按钮 | POST retention/holds{audit_id,reason,expires_at}；无客户端tenant_id | task防重；成功清当前草稿及未保存基线并重读；身份/作用域变化清草稿 | 保护成立后被清理候选执行再次排除，无跨域关系；旧身份的确认不恢复草稿 |
| P32-C41 | 保护表审计ID列 | AuditHold.audit_id:string，row-key=id | 与保护记录id分开 | 解除请求使用hold.id，不能误用audit_id |
| P32-C42 | 保护原因列 | reason纯文本 | 不执行HTML | 長依据可见且不含秘密 |
| P32-C43 | 保护到期列 | expires_at:null显示“显式解除前保留” | 空不是已到期；保留依据按服务端判定 | NULL保护不会自动释放 |
| P32-C44 | 保护状态列 | released_at:null显示“保护中”，否则“已解除” | 历史解除事实保留 | 失败不预改已解除 |
| P32-C45 | 解除保护按钮与确认 | 未released+retention_manage；POST holds/release{id}；确认显示auditId | 精确hold ID，取消无写，账号世代变化不发旧请求 | 解除保留历史，而非删除保护事实；确认目标不随排序变化 |
| P32-C46 | 重新采样按钮与采样错误 | status_read；GET status；loading/error独立 | 只采样，不重启/执行命令；失败不假全绿 | API拒绝/依赖down明确，与业务就绪分开 |
| P32-C47 | 采样时间显示 | RuntimeStatus.observed_at | 实际采样时刻，不取前端当前时间替代 | 旧采样失败保留旧事实且可识别 |
| P32-C48 | JVM运行时长显示 | uptime_millis转换floor秒 | 0真实，不承诺进程不会重启 | 与服务器采样一致 |
| P32-C49 | 线程数显示 | threads | 当前JVM数，不是任务数 | 不由UI活动数量计算 |
| P32-C50 | 堆使用显示 | heap_used_bytes转换MiB一位小数 | 原始字节来自服务器，单位正确 | 转换关系准确，不把最大堆当已用 |
| P32-C51 | 连接池活跃/空闲显示实例 | database_pool_active/database_pool_idle；null“未采集”，0保留 | 未采集不显示0或健康 | 两字段分别核对null/0/正数，不推定数据库业务通过 |
| P32-C52 | 探测组件列 | probes[].name，row-key=name | 真实注册探针 | 不生成虚构依赖 |
| P32-C53 | 实测状态列 | probes[].status，包括unavailable/down等 | 未配置、不可用、故障分开，不硬编码“正常” | 禁用/故障依赖准确显示 |
| P32-C54 | 探测耗时列 | duration_millis，单位毫秒 | 测量值，不设未批准性能预算 | 0保持0，耗时不是业务端到端延迟 |
| P32-C55 | 探测说明列及空态 | probes[].detail；无采样提示“点击重新采样获取真实状态” | 说明脱敏；未采样不表示所有依赖健康 | 长说明可达，秘密连接地址/口令不泄露 |

预览、冻结执行、保护创建/解除、失败回滚、真实采样与审计导出是独立高影响流程。仅由侧栏打开本页或后端隔离测试通过，不能登记这些UI流程、桌面键盘/焦点、所有视口和主题已验收。
