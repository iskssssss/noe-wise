# P28 菜单、字典与配置逐控件规格

本页承接[P26–P32 共同原子合同](../06-后台逐控件规格.md#基础页面共同原子合同)；状态/证据归[验收索引](../../08-数据与工具/ui-acceptance-index.json)。双宿主入口为 `/platform/foundation/catalog`、`/admin/foundation/catalog`，来源为 [CatalogPage.vue](../../../frontend-shared/src/foundation/catalog/CatalogPage.vue)、[types.ts](../../../frontend-shared/src/foundation/catalog/types.ts)、[appearance.ts](../../../frontend-shared/src/foundation/appearance.ts) 及 [navigation.ts](../../../frontend-shared/src/foundation/navigation.ts)。下表请求以 `foundation/catalog/` 为根，完整替换携带 `expected_revision`；不存在的关系版本为 0，不从另一对象修订推断。

字段权威为 [CatalogValidation](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/CatalogValidation.java)、[DictionaryService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/dictionary/DictionaryService.java)、[NavigationService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/navigation/NavigationService.java)、[PreferenceService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/preferences/PreferenceService.java) 与 [EntitlementService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/entitlements/EntitlementService.java)。稳定编码统一为 `[a-z][a-z0-9_.-]{0,63}`；名称 trim 后按 Unicode 码点计数。空链接提交 null 清除；菜单只能引用 [ControlledRoutes](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/catalog/navigation/ControlledRoutes.java) 注册的 route_key，不能自由修改 URL 或动作权限。
