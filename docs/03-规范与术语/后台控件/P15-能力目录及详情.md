# P15 能力目录及详情实际控件合同

通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

平台目录通过共享 `CapabilityCatalog` 读取平台能力集合，当前按关键词和类型在前端过滤；状态筛选与分页要求尚未由该组件实现。目录使用独立详情路由，详情再加载定义与版本。平台资源必须满足 `tenant_id=NULL`，创建、草稿编辑、校验、发布均受 `platform_admin` 控制。

机构与平台详情页共用 `CapabilityDetail`：首屏及刷新通过 `GET /api/v1/[admin/]capabilities/versions/summaries?definition_id=...` 仅读取版本 ID、版本号、名称、说明和状态五字段，不预读 descriptor 或包文件。接口要求 `foundation.capabilities.read`，保留各自定义和版本可见范围及全部可见状态，按创建时间倒序、同值按 ID 倒序。非 Skill 版本仅在查看、编辑或恢复目标时读取精确详情，成功核对版本、定义及能力类型后才替换编辑内容；读取失败或取消保留原编辑状态。Skill 卡片继续导航到文件工作台，不预读包正文。以下未涉及的历史规格目标不因此视为已完成。
