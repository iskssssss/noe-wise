通用组件 API 以 [Element Plus](https://element-plus.org/zh-CN/component/overview.html) 官方文档为准，组件与页面边界遵循[后台逐控件规格](../06-后台逐控件规格.md#1-使用方式与事实边界)。本文保留业务字段、权限、精度和数据保护验收编号；旧 Vben/VXE 名称、workspace 辅助函数及 i18n key 仅作历史规格追溯，不证明当前源码仍有相同实现。当前文案与组件接线以所链接页面及共享组件为准，业务验收要求保留，实施差距按验收索引核对。

本文是[后台逐控件规格](../06-后台逐控件规格.md)的页面正文，约束实际控件接线、状态、数据和验收。视觉数值由[视觉规范](../../02-架构与设计/09-前端视觉与交互规范.md)维护；实现差距与测试证据在[验收索引](../../08-数据与工具/ui-acceptance-index.json)跟踪。下表描述规格与源码绑定，不表示已经通过验收。

## 后端契约绑定与未绑定项

- 权限边界由 [SystemAgentController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/SystemAgentController.java) 的类级 @RequireRole(PLATFORM_ADMIN) 定义；列表读取、详情读取、创建、删除及状态动作均要求 platform_admin。后端实际路由前缀为 /api/v1/admin/system-agents，前端 API 封装可省略该前缀。
- 创建请求字段为 agent_key、name、description、execution_mode；控制器只对 agent_key、name、execution_mode 做 @NotBlank，后端服务还要求 agent_key 匹配 [a-z][a-z0-9-]{2,99}、不得使用 memory-extraction、task-context、context-summary，且 execution_mode 严格为 MODEL_TASK 或 AGENT_RUN。服务端不替请求值做 trim；页面的 trim 和长度提示属于前端行为。
- 后端服务对名称要求非空且最多 128 个字符，对非空描述要求最多 2000 个字符；创建会生成草稿配置，MODEL_TASK 初始 max_steps=1 且无挂载，AGENT_RUN 初始 max_steps=10 且无挂载。具体配置校验见 [SystemAgentService.java](../../../backend-java/skillforge-core-agent/src/main/java/com/skillforge/core/agent/systemagent/SystemAgentService.java)。
- 列表状态只能按当前返回的 draft、published、disabled、archived 解释；发布会递增 published_version，已发布智能体可停用，只有带已发布配置的停用智能体可启用；已发布状态不能直接归档，存在 purpose 的智能体不能归档。
- 删除按钮的后端可执行条件比列表展示条件更严格：SQL 同时要求 status=draft、purpose IS NULL、published_version IS NULL 且不存在任何运行记录，并使用 expected_revision 做 CAS；实现见 [SystemAgentMapper.xml](../../../backend-java/skillforge-core-agent/src/main/resources/mapper/systemagent/SystemAgentMapper.xml)。
- 所有写请求都携带正整数 expected_revision 并执行乐观并发校验，冲突返回 409；页面不得在未取得服务端返回对象前伪造状态、版本或删除结果。
- 该页面的搜索、分页、按钮可见性、名称/描述的前端长度提示属于页面实现；后端契约只由上述控制器、服务和 Mapper 条件约束，未另外声明列表排序、搜索参数或分页协议。
