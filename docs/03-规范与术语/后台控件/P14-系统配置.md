## 后端契约绑定与未绑定项

- 系统配置接口由 [SystemSettingsController.java](../../../backend-java/skillforge-platform-service/src/main/java/com/skillforge/platform/controller/SystemSettingsController.java) 提供，并受类级 @RequireRole(PLATFORM_ADMIN) 保护；列表、历史、更新和回滚实际路由前缀为 /api/v1/admin/system-settings。
- [OperationalSettingsRegistry.java](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/settings/OperationalSettingsRegistry.java) 是分组、字段类型、默认值、范围、选项和跨字段规则的唯一注册表。当前分组为 task_budget、calls、memory、knowledge、sandbox、artifacts、rate_limits、billing、prompts；页面不得把分组或字段集合写死成较小的前端抽象。
- 管理接口的 Field DTO 只返回 key、label、type、unit、minimum、maximum、choices、secret。注册表内部还有 allowBlank、defaultValue、maxLength 和 templateVariables，但当前 DTO 没有暴露这些属性；因此页面的 required/default/help/maxLength/templateVariables 展示目前属于契约缺口，不能把前端猜测当成服务端 schema。
- 后端支持的字段类型只有 number、boolean、string、select、text。所有显式提交的值都拒绝 null；非 secret 字段缺失会报缺少字段，secret 字段在更新时可省略以沿用当前值；未知字段会被拒绝。select 必须严格命中 choices，number 必须是有限数字并满足注册范围，文本类字段按注册表的非空和长度规则校验。
- task_budget 只提供普通、协作、团队三个场景各五项根额度，统一保存一个修订；默认数值与角色派生规则见 [共享任务预算](../../../harness-design/03-上下文视图与执行优化.md#24-共享任务预算与持久结算)。业务/工具/知识次数为正 int，累计总 Tokens 为正 long，活跃时长为 1–604800 秒。
- knowledge 的 chunk_size 默认 500（1–100000），chunk_overlap 默认 50（0–99999）且必须小于 chunk_size；default_indexing_mode 只能是 high_quality|economical，default_retrieval_mode 只能是 semantic|full_text|hybrid。sandbox.memory_limit 是字符串，必须匹配正则 [1-9][0-9]*[kKmMgG]。
- calls、memory、artifacts、rate_limits 等继续保留资源与产品行为参数；删除画像摘要批量、容器控制超时、工作区清理周期、产物清理周期的编辑入口。上下文策略版本从只读 `/context-policy` 返回，页面展示代码身份。prompts 三个 text 字段各有 200000 字符上限并校验模板变量。
- 技术上下文校验由代码策略与实际渲染负责，压力裁剪计入包装与标记。运营 billing 启用 exchange_rate 或 usage_reconciliation 时对应 endpoint 不能为空。旧分组及旧字段写入明确拒绝。派生角色额度由 `derived_budgets` 返回只读说明，不进入 writable values。
- billing 中 endpoint 字段允许空字符串，API key 字段允许空字符串且为 secret；其他 string 字段按注册表的 allowBlank 和长度校验处理。历史版本和当前管理视图不回显 secret 值，更新与回滚后 revision 均为 expected_revision+1，冲突返回 409，未知 group 返回 404；实现见 [OperationalSettingsService.java](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/settings/OperationalSettingsService.java)。
- 页面当前的动态渲染、错误文案、脏态、历史抽屉和 secret 空输入处理必须服从以上实际 schema；尤其不能因为 Field 未返回 required/default/help/maxLength/templateVariables 而声称后端已经提供这些元数据。
