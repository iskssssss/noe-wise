# P31 导入导出与管理任务逐控件规格

共同合同见[P26–P32](../06-后台逐控件规格.md#基础页面共同原子合同)，状态与证据归[验收索引](../../08-数据与工具/ui-acceptance-index.json)。入口为 `/platform/foundation/jobs`、`/admin/foundation/jobs`；页签和文件入口见 [FoundationPage.vue](../../../frontend-shared/src/foundation/FoundationPage.vue)，实现为 [FoundationJobsPage.vue](../../../frontend-shared/src/foundation/assets/FoundationJobsPage.vue)，类型见 [contracts.ts](../../../frontend-shared/src/foundation/assets/contracts.ts)。下表接口以宿主 `foundation/` 为根。

合同权威为 [FoundationJobService](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/jobs/FoundationJobService.java)、[FoundationCsv](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/jobs/FoundationCsv.java)、[CsvTransferHandler](../../../backend-java/skillforge-core-foundation/src/main/java/com/skillforge/core/foundation/jobs/CsvTransferHandler.java) 和已注册领域处理器。只执行已注册 handler 与有限 option_fields；不接收代码、SQL、客户端租户或成员身份。导入先无业务写入预检，再以逐行真实事务执行；取消只停止未提交后续行，已提交行保留。默认结果保留七天，过期释放文件引用。

## 稳定对象合同

| 编号 | 对象与文案/组件 | 数据、触发与权限 | 状态、异常与恢复 | 具体验收断言 |
| --- | --- | --- | --- | --- |
| P31-C01 | 任务说明与区域名称 | section“管理任务中心”；说明预检/逐行/取消/七天结果保留 | 不宣称受理即完成，不宣称取消回滚已提交行 | 文案与真实worker执行及过期事实一致 |
| P31-C02 | 文件/任务业务页签 | jobs.read 控制任务，files.read控制文件；jobs路由默认任务 | 共享分区仍单独授权 | 只任务读账号没有文件入口，直达文件仍拒绝 |
| P31-C03 | 处理器读取错误 | GET jobs/handlers返回授权投影；错误ElAlert | 读取失败不提供假处理器 | 无权限handler不出现；恢复重读不发submit |
| P31-C04 | 任务/详情/写错误与受理反馈 | jobs/detail/action各自错误；“任务已受理：ID” | 受理与终态分开；身份变化清旧消息 | 服务器受理后即使worker未运行只显示排队/受理 |
| P31-C05 | 处理器选择 | jobs.create；handlerCode取真实code/title；只能注册项 | 切处理器清旧optionValues与预检基线；busy、已受理或提交待确认时禁用 | 旧handler选项不发送；不能客户端注入处理器；未知提交不靠编辑换键 |
| P31-C06 | 导入/导出操作单选 | operation=import/export；按can_import/can_export禁用 | 当前无import但可export切为export；变更使预检失效 | handler权限与动作一致，读权限不等于执行权限 |
| P31-C07 | 动态领域选项字段实例 | option_fields[].code/label/required/hint；string值按注册key提交 | 缺required本地提示；只提交注册字段；handler变更清草稿 | 每个真实field key独立验证；未知选项拒绝，不显示技术JSON编辑器 |
| P31-C08 | CSV表头说明 | currentHandler.columns，纯文本列名 | 由处理器声明，不推测密码/租户列 | 列名与真实预检一致，秘密材料不导出 |
| P31-C09 | UTF-8 CSV文件选择与已上传名 | import；先POST files/upload，返回file_id；accept=.csv | 上传成功不等于预检；失败不伪造材料ID；换材料使预检失效 | 编码/格式/大小拒绝可读；业务行尚未写入 |
| P31-C10 | 导入预检按钮 | import且handler/file存在；POST jobs/preflight{handler,file_id,options} | busy防重；预检只读、旧材料结果不能启用新任务 | 错误CSV零业务写；材料/选项改变后原valid作废 |
| P31-C11 | 预检结果告警 | valid/row_count/errors；有效显示总行数，无效说明“业务数据未写入” | 失败/空输入不能伪通过 | 行数与真实解析一致，非JSON假进度 |
| P31-C12 | 预检错误数据行列 | errors[].row_number | 对应CSV真实行号，含表头偏移；不是数组索引 | 第一数据行编号与输入位置一致 |
| P31-C13 | 预检错误字段列 | errors[].field | 表头字段或row，稳定字段定位 | 错误不串另一行/字段 |
| P31-C14 | 预检纠正说明列 | errors[].message | 公开说明，不包含原单元格秘密 | 密码/token/SMTP材料不进入错误返回/日志 |
| P31-C15 | 提交/重试原提交/查看已受理任务按钮 | jobs.create+handler动作权限；import须checked.valid；首次POST前冻结完整command与key，重试原body/key | 未提交草稿变更才更新key；未知后锁表单，明确重试仍是幂等POST，不能称只读；首次完整明确拒绝才恢复编辑 | 网络/5xx/损坏回执后不换键；旧未知不被后续拒绝清除；查看始终定位本次已受理任务，不随历史详情选择变化 |
| P31-C16 | 新建任务按钮 | 仅submitted显示；明确清预检并生成新idempotencyKey | 不是未知结果自动重新提交 | 已受理任务仍保留真实详情，新任务需重新预检 |
| P31-C17 | 刷新任务按钮 | GET jobs?page&page_size | 只读poll，不submit/replay；loading状态独立 | 重复刷新不产生新worker执行 |
| P31-C18 | 任务列、handler链接与ID | FoundationJob.handler/id:string；row-key=id；链接inspect真实对象 | 任务ID不取整；同handler多任务分开 | 选行后请求detail/errors携带精确job_id |
| P31-C19 | 操作列 | operation=import/export显示导入/导出 | 真实动作，不从文件扩展推断 | 请求操作与回执一致 |
| P31-C20 | 状态列 | queued/running/cancel_requested/succeeded/failed/cancelled/expired映射业务文案 | 状态按worker权威读；未知状态保留码 | cancel_requested不先显示cancelled；failed不显示已完成 |
| P31-C21 | 进度列 | completed_rows/total_rows/error_rows | 无本地估算百分比；0合法；已提交行保留 | 取消/故障后真实行数和事务副作用一致 |
| P31-C22 | 创建时间列 | created_at；formatDateTime | 服务端受理时刻 | 重启/刷新不变创建时间 |
| P31-C23 | 详情按钮 | inspect固定selectedId，GET jobs/detail与jobs/errors | 切任务立即使旧错误材料失效；新任务材料读取失败仍保该任务详情，不显示旧任务错误 | A错误或迟到回包不挂在B状态下，selectedId与请求/显示一致；新提交任务同样切材料归属 |
| P31-C24 | 下载结果按钮 | result_file_id非空；GET files/download受控Blob | 文件域再次鉴权；结果过期或外域拒绝；URL释放 | 下载内容是权威CSV，错误响应不保存成CSV |
| P31-C25 | 取消按钮与确认 | jobs.cancel且queued/running；POST jobs/cancel{job_id} | 确认“取消后续处理，已提交行保留”；账号变更不发旧命令 | 取消确认无副作用；服务器终态优先，不盲覆盖 |
| P31-C26 | 分页与页大小 | 1起页、total真实；10/20/50/100；本人默认偏好 | 改大小回1；临时选size不保存本人默认 | 50条真实查询；末页变化不循环 |
| P31-C27 | 详情任务身份显示 | selected.id；ElDescriptions | 只读，主键不是handler code | 标题与错误/result全部同job |
| P31-C28 | 详情状态显示 | selected.state真实映射 | 不复用上一条状态 | 接口状态刷新准确 |
| P31-C29 | 详情失败说明 | error_message:null显示— | 不用null表示成功，也不泄露原单元格/凭据 | failed时保留公开原因，空说明不伪造错误 |
| P31-C30 | 结果保留截止显示 | expires_at服务端绝对时刻 | null占位，过期按真实状态 | UI时间与文件保留一致，不本地延长截止 |
| P31-C31 | 逐行错误列表、错误告警 | GET jobs/errors?job_id&page_size=200；loading/错误/成功无错分开；失败可单独重读当前job材料 | 先展示200；超过200说明下载完整材料；重读不提交任务、不清新建草稿 | 读取失败不是“没有逐行错误”，错误行不泄露秘密，也不复用其他任务材料 |
| P31-C32 | 逐行错误数据行/字段/纠正说明列实例 | TransferRowError.row_number/field/message，规则同C12–C14 | 每列按真实field key独立实例 | 行/字段定位正确，部分成功事实仍可核对 |
| P31-C33 | 超200错误行说明 | selected.error_rows>200；提示下载结果查看完整材料 | 不声称200行是所有错误 | 错误总数与前200/完整CSV范围正确 |
| P31-C34 | 轮询、离开与作用域清理 | poll只读jobs及当前detail；定时器/资源由组件管理；未提交材料/选项及待确认command计入脏态 | 卸载清timer并使旧世代失权；提交中离开受保护；身份变更清草稿及本页待确认状态 | 空选项导出未知时也有离开保护；旧scope迟到回执不复活待确认命令；不声称跨刷新持久恢复 |

导出真实流程必须同时核对提交快照、worker终态、CSV内容、精确任务身份和受控下载；列表/按钮可见或POST返回200不足以证明导出完成。未执行的导入错误、部分成功、取消、未知受理、重启恢复和桌面交互仍按各自项登记。
