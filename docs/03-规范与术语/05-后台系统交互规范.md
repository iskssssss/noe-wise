# 后台系统交互规范

## 1. 事实源与适用范围

本文是 灵知 平台后台（`frontend-platform`）及其必要后端协作的交互规则唯一事实源；机构后台复用的共享交互能力遵循本文与[前端视觉与交互规范](../02-架构与设计/09-前端视觉与交互规范.md)的职责边界。

本文定义桌面后台的导航、标签、列表、表单、弹层、文件编辑、版本操作和异常状态；后台普通导航、菜单、标签页和控件交互采用 项目轻量单页导航与 Element Plus 行为，颜色、字号、字体、间距、圆角、主题令牌、层级令牌和动效由[前端视觉与交互规范](../02-架构与设计/09-前端视觉与交互规范.md)唯一维护。

本文描述已批准目标规则，不记录实施进度、测试结论或当前缺口；页面职责目标见第 12 节。

请求竞态、表单基线、字段错误路径、精确值与缓存作用域等通用实现要求归[前端工程规则](../../.agents/skills/nw-engineering/references/engineering-standards.md#前端状态与接口消费)，本文维护用户可观察的后台交互和规则编号；现有逐控件实现事实不构成通用契约的例外。

所有规则均以编号作为验收索引；实现、测试、评审和缺陷引用规则编号，不以页面截图或口头约定替代规则。

平台后台采用桌面优先的标准 B 端系统结构，主题和普通交互遵循 后台公共布局与 Element Plus；模板自带的响应式能力可以保留，但不构成手机端或触屏端支持承诺。后台需要的后端查询、详情、写入、错误、批量或导出能力可以按本文目标补齐接口，但不得降低权限校验、租户隔离、幂等、并发一致性、金额与数量精度、审计和错误契约要求。

导航、菜单、标签页、Drawer、Modal、反馈和表格的外观、基础状态与普通键盘行为直接采用 后台公共布局与 Element Plus；本规范只补充业务身份、权限、数据、未保存和提交中保护等平台语义，不要求另建自研菜单或基础控件。

## 2. 全局视觉与布局规则（A）

- A01 品牌统一：中文名称使用“灵知”，英文名称使用“NoeWise”；品牌、登录页、浏览器标题与下载命名按当前语言分别使用，不将中英文名连写。
- A02 字体层级：正文、页面标题、区块标题、辅助文字分别绑定 `--font-size-base`、`--font-size-2xl`、`--font-size-lg`、`--font-size-xs`；字号和行高数值仅在[前端视觉与交互规范](../02-架构与设计/09-前端视觉与交互规范.md)维护。
- A03 数字与代码：金额、数量使用等宽数字；编码、版本标识和代码使用等宽字体。
- A04 间距体系：统一页面边距、区块间距、字段间距、按钮间距，使用现有间距令牌。
- A05 控件与密度：按钮、输入、选择、反馈和表格密度使用 后台公共布局与 Element Plus 的公开能力；页面不另设基础控件包装、私有尺寸常量或触屏专项入口。
- A06 颜色语义：主操作使用中性色；成功、警告、危险同时具有文字或图标标识。
- A07 控件状态：补齐正常、悬浮、按下、聚焦、禁用、只读、加载、错误状态。
- A08 主题完整性：表头、固定列、菜单、抽屉、编辑器、提示和滚动条全部适配明暗主题。
- A09 首屏主题：挂载前应用主题，避免刷新时闪白或闪黑。
- A10 应用壳层：平台后台的侧栏、顶栏、面包屑和内容区使用后台公共布局与主题配置；机构后台使用其所属 后台公共资源 壳层，不在本规范复制尺寸或实现路径。
- A11 内容宽度：列表充分使用可用宽度；表单按分组组织，避免字段在超宽屏无限拉伸。
- A12 页面滚动：列表与详情默认使用内容区滚动，不强制固定表体高度；确有密集比较需求时采用局部表格滚动，编辑器各工作区独立滚动。
- A13 自适应高度：内容按实际数据和可用工作区布局，表格不绑定固定表体高度，主要操作和分页保持可达。
- A14 布局稳定：加载、错误、筛选展开和按钮 loading 不导致主要操作大幅位移。
- A15 页面最大化：提供内容区最大化/还原，隐藏辅助导航后仍保留清晰的还原入口。
- A16 动效偏好：减少动效模式下取消非必要过渡和平滑滚动。

## 3. 左侧导航栏规则（B）

- B01 菜单分组：按概览、机构与计费、资产与能力、系统管理四个业务分组排列，名称、图标和页面标题一致。
- B02 图标完整：补齐技能维护台等缺失图标，避免多个不同功能无区分地复用图标。
- B03 当前项高亮：详情页仍高亮所属列表入口，并设置正确的可访问选中状态。
- B04 分组展开：分组支持展开/收起；进入某分组下页面时自动展开该分组。
- B05 折叠导航：折叠后保留图标、选中态和功能提示，不留下不可辨认的空白区域。
- B06 导航滚动：菜单超出高度时仅导航区滚动；当前菜单可自动滚动到可见位置。
- B07 长名称：文本截断后可查看完整名称；提示浮层不被侧栏裁剪。
- B08 普通点击：切换当前单页路由；重复点击当前地址不清空草稿或自动刷新。
- B09 浏览器习惯：链接保留 Ctrl/Cmd+点击、中键打开浏览器新标签的行为。
- B10 返回工作台：品牌区域提供明确的工作台入口。
- B11 浮层关闭：Drawer、Modal 和菜单遵循 Element Plus 的关闭、Esc、焦点限制和焦点恢复行为。
- B12 导航拦截：存在未保存修改时，导航与其他离开入口使用同一确认流程；取消后菜单高亮不变。
- B13 权限变化：不可访问入口按既有权限隐藏或禁用；持久化菜单状态不能绕过路由鉴权。
- B14 对象明确：右键菜单作用于被点击的菜单项，不作用于当前已激活页面。
- B15 不自动导航：单纯右键打开菜单不会切换页面。
- B16 保留原生能力：导航之外的普通链接、文字和输入区域保持浏览器原生右键行为。

导航使用浏览器原生链接与右键行为，不实现应用导航专用右键菜单。原 B-MENU01–B-MENU03 仅用于历史追溯。

## 4. 顶栏与面包屑规则（C）

- C01 面包屑层级：展示分组、功能、对象；上级为可点击链接，当前对象为文本。
- C02 动态对象名：机构、智能体、模板和模型详情显示真实名称；加载阶段使用清晰占位标题。
- C03 名称更新：保存重命名后同步更新页头、面包屑、业务页签及浏览器标题。
- C04 超长面包屑：中间层级可压缩，当前对象仍可辨认，完整名称可查看。
- C05 账号入口：显示当前账号和平台身份，提供退出登录；侧栏折叠后仍可操作。
- C06 主题入口：三种主题状态明确，刷新后恢复选择。
- C07 系统状态入口：进入系统状态页，避免与刷新或页面最大化图标混淆。
- C08 顶栏入口：顶栏入口、账号操作和次要动作使用 后台公共布局 的标准布局与菜单行为。
- C09 退出保护：主动退出前检查未保存修改；取消退出时保持登录和页面状态。
- C10 退出清理：退出后停止请求与轮询、关闭浮层、清除当前账号的业务页面数据与请求状态。

## 5. 页面标签与右键菜单规则（D）

当前后台采用单页路由。D01–D36 与 D-MENU01–D-MENU12 所描述的应用内标签、标签缓存与右键菜单不再适用；旧编号仅用于历史证据追溯，不作为当前实现要求或自动视为验收通过。并行任务使用浏览器原生标签页。

页面内有实际业务分区时可直接使用 Element Plus Tabs，不能将业务分区与应用导航缓存混为一体。

## 6. 页面导航、缓存与状态恢复规则（E）

- E01 直达详情：刷新详情地址或粘贴地址进入时，可独立加载完整页面。
- E02 浏览器前进后退：面包屑、侧栏和业务页签随路由同步。
- E03 返回列表：恢复原筛选、页码、页大小和滚动位置。
- E04 筛选地址化：仅有效的列表条件写入 URL；连续输入不制造大量浏览历史。
- E05 参数校验：非法页码、页大小、页签和枚举值恢复为页面默认值。
- E06 页面读取：进入页面按当前授权重新读取；不维护 KeepAlive 页面缓存。
- E07 变更刷新：新增、编辑、发布、启停影响对应领域列表，不全站刷新。
- E08 资源释放：离开路由后释放页面实例、事件监听、定时器与观察请求。
- E09 对象不存在：详情对象删除或失效时显示专属状态和返回列表入口。
- E10 会话失效：清晰提示重新登录并保留目标地址；不自动重放写请求。

## 7. 筛选、表格和分页规则（F）

### 7.1 筛选与查询

- F01 字段名称：搜索、状态、类型、机构等条件有可访问名称，不仅依赖 placeholder。
- F02 统一提交：查询按钮和 Enter 执行相同查询；输入法候选确认不误触发查询。
- F03 条件重置：清空条件、回到第一页并查询，同时更新 URL。
- F04 高级条件：多行条件支持展开/收起；收起时保留已应用条件并显示数量。
- F05 输入规范化：去除适当首尾空白，保留有业务意义的字符。
- F06 查询防重：一次用户动作只产生一次有效查询，避免页大小监听和分页事件重复请求。
- F07 请求竞争：旧请求不能覆盖新结果，也不能提前清除新请求的 loading。
- F08 数据范围：区分服务端分页、完整数组和受限返回集合，明确显示真实查询范围。

### 7.2 表格展示与设置

- F09 列表结构：统一页头、筛选、主操作和结果层级；表格、摘要或分组按用户任务选择，分页只在真实需要时提供。
- F10 结果数量：区分匹配总数、当前展示条数和受接口限制的返回数量。
- F11 行键稳定：使用业务 ID，分页或排序后操作仍对应正确对象。
- F12 名称入口：主要名称使用明确链接；点击行内按钮不会同时进入详情。
- F13 状态标签：使用中文状态及统一语义色，不直接展示难懂的原始枚举。
- F14 时间格式：日期时间统一显示为 `YYYY-MM-DD HH:mm:ss`（24 小时制、月日时分秒补齐两位），纯日期为 `YYYY-MM-DD`，月份为 `YYYY-MM`。依照[全系统时间契约](../02-架构与设计/13-全系统时间契约.md)，业务日期时间固定为北京时间 `Asia/Shanghai`；无偏移的业务日期时间按北京时间解释，日期控件的选择转换成带 `+08:00` 的绝对时刻提交，需要说明时区的字段标明“北京时间”。纯日期和月份保留日历精度，不作时区换算或补造时刻；已展示字段的缺失、空白及无效日期统一为 `—`。表格、详情、提示和日期控件显示遵循同一规则，原始 JSON 和业务正文保留原值。
- F15 金额精度：保持接口精度，显示币种和计量单位，金额右对齐。
- F16 长文本：截断、提示、复制和详情入口配合使用，避免长内容撑高每行。
- F17 固定列：宽表确需固定关键识别列和操作列时，横向滚动背景不透明、不叠字；不为普通窄表强制增加固定列。
- F18 固定表头：采用局部滚动或固定表头时，表头位置和层级正确，不被全局顶栏覆盖。
- F19 表格密度：默认采用适中密度；仅在真实高密度阅读需求下提供密度选择，不要求每张表提供或持久化设置。
- F20 列显隐：提供列设置时放入浮层；名称等必要列不可隐藏，不允许隐藏全部数据列。
- F21 列宽调整：优先按内容自动分配宽度；实际提供调整时遵守最小宽度，操作列不会被压到不可用。
- F22 列顺序：仅在真实使用需求下提供列顺序调整，关键固定列保持其区域。
- F23 重置设置：提供自定义设置的表格可一键恢复实际支持的默认列宽、顺序、显隐或密度。
- F24 偏好有效性：已持久化的列设置在字段删除后清理过期项，新增列按默认策略显示；普通列表不强制新增偏好存储。
- F25 排序真实性：服务端列表只提供接口支持的排序；完整数组可以按完整数据排序后分页。
- F26 行操作收敛：主要操作直接显示，其余收进“更多”；处理中按行显示忙状态。
- F27 行右键菜单：复用该行已有合法操作，增加复制标识等辅助动作；右键不自动执行或切换对象。
- F28 选择状态：存在真实批量操作时才显示选择列，并正确显示未选、全选和半选；批量操作区显示已选数量，未选时不允许执行。
- F29 选择范围：选择仅针对当前结果页，操作前明确当前页范围和已选对象；切换页码或查询条件时清空，避免误操作其他页对象，不暗示已选中全部筛选结果。
- F30 导出边界：只保留已有真实导出能力，明确导出对象和范围。
- F31 虚拟滚动：长列表滚动无缺行、重叠和操作错位；密度改变后重新测量。
- F32 静态信息表：无查询和分页需求的小表使用简单表格，不强行加入无效工具栏。

### 7.3 分页与列表状态

- F33 分页操作：上一页、下一页、总页数、页大小和跳页行为一致。
- F34 页大小：普通列表默认 20 条，可选 10/20/50/100；受接口限制的列表按真实能力展示。
- F35 跳页校验：空值、小数、零、负数和超过末页的输入不产生非法请求。
- F36 边界禁用：第一页、最后一页、零条数据时正确禁用相关操作。
- F37 页码修正：删除或筛选导致当前页不存在时，回到有效页。
- F38 刷新语义：刷新当前列表保留有效页码；查询新条件或重置才回第一页。已显示数据、页码、页大小及已应用筛选须属于同一次成功读取；请求失败保留旧数据时保持或恢复原分页与已应用条件，不覆盖用户尚未提交的筛选输入。
- F39 空态分类：首次无数据提供创建入口；筛选无结果提供清空条件；首次失败也保留可见恢复入口，不能因列表为空把失败说明和重试一起隐藏。
- F40 刷新状态：后台刷新保留已有内容并标明刷新中；首次加载使用对应布局骨架。

## 8. 表单、选择器和动态条目规则（G）

- G01 表单分组：按当前业务任务组织常用字段，低频配置可折叠并展示当前值摘要；可从已授权上下文带入或继承的值说明来源和覆盖方式，减少重复填写。
- G02 标签关联：标签点击可聚焦对应输入，帮助和错误与控件正确关联。
- G03 必填提示：必填字段明确，选填含义清楚。
- G04 输入示例：placeholder 给出输入目标或示例，不机械重复标签。
- G05 校验时机：提交校验必做；不在用户尚未完成的输入中途报错，已发生错误的字段在修改后及时更新提示。说明修正方法，字段无效与服务不可用分别反馈。
- G06 错误定位：字段校验失败自动展开错误所在分组并滚动聚焦首个错误字段，避开固定栏遮挡；长表单多处错误提供链接到对应字段的错误摘要，短表单沿用原位错误。服务不可用等非字段错误使用页面顶部 Message，不指向无关字段。
- G07 原值恢复：取消或撤销恢复本次编辑前的数据；恢复动作不调用写接口。
- G08 脏状态：修改后标记未保存，改回原值后取消标记。
- G09 保存防重：连续点击和快捷键不会重复提交。
- G10 失败保留：提交失败保留输入与字段错误，不清空表单或关闭抽屉。
- G11 成功反馈：保存成功更新本次提交的基线、版本信息和相关列表；未提交的其他字段或在途后继续编辑的内容仍保留，具体合入与禁用策略见[前端状态规则](../../.agents/skills/nw-engineering/references/engineering-standards.md#前端状态与接口消费)。
- G12 密码输入：显隐切换不丢焦点，密码自动填充属性正确；密码管理器、粘贴与验证码输入按 [UI 输入规则](../../.agents/skills/nw-ui-ux/SKILL.md#弹层菜单与输入)执行。
- G13 密钥语义：明确“未配置”“已配置”“留空保持原值”，不显示伪造掩码作为真实值。
- G14 数字字段：限制范围、步长、整数或小数规则；清空不被误当作零。
- G15 高精度金额：避免经过 JavaScript 浮点转换破坏金额字符串。
- G16 单选与多选：区分全部、未选择、无可选项；选中项不能与 placeholder 混淆。
- G17 选项搜索：引用对象优先展示可理解名称和必要标识，完整数据可本地搜索，远程选项绑定真实目录或搜索接口；接口缺口不得伪装成完整集合，失效引用不自动改绑。
- G18 选项加载：加载、加载失败、无匹配、全部禁用均有清晰状态。
- G19 级联重置：提供方、服务、协议等上级变化后清除失效下级值。
- G20 长选项：允许合理换行或查看全文，浮层宽高不超出视口。
- G21 多选摘要：过多标签折叠为数量摘要，支持查看和移除已选项。
- G22 日期控件：清除、月份切换、禁用日期和范围边界一致；起止日期关系正确。
- G23 字段说明：影响填写和判断的单位、范围、留空/清除行为、依赖、生效时机及危险影响就近可见；超时、额度、预算、Token 等字段写清单位和既有规则。名称等含义明确的字段不强制增加 Tip，相关字段可共享说明。动态字段按 schema 表达必要类型、必填及约束，不编造缺失 description；帮助通过 aria-describedby（代码编辑器使用 described-by）关联控件。必要说明不能仅藏在 placeholder 或 Tooltip，独立会话端采用同一信息原则。
- G24 动态新增行：新增后聚焦第一字段，行编号或标题可辨认。
- G25 动态删除行：明确删除对象；仅删除本地未保存条目时提供轻量撤销。
- G26 重复条目：按现有契约阻止重复能力、槽位或角色，并定位冲突条目。
- G27 动态行稳定性：新增、删除或调整内容后，错误和输入不串到其他行。
- G28 只读表单：只读状态清晰，仍可选择和复制内容，隐藏无意义保存入口。
- G29 修订冲突：冲突时保留本地输入，重新加载前说明将放弃哪些修改。
- G30 键盘提交：普通表单支持合理的 Enter 提交；多行文本和编辑器 Enter 保持换行。

## 9. 抽屉、对话框、提示与反馈规则（H）

- H01 弹层分工：简单创建/编辑用抽屉，确认用对话框，复杂编辑进入独立维护页。
- H02 标题具体：显示“编辑某机构”“回滚至某版本”等明确对象。
- H03 固定操作区：长内容滚动时，标题、关闭入口和底部操作仍可达。
- H04 关闭入口一致：关闭按钮、取消、Esc、遮罩使用同一离开检查。
- H05 遮罩规则：编辑抽屉默认不因点击遮罩关闭；无修改的轻量展示弹层可关闭。
- H06 提交中关闭：不可安全中断的在途提交禁止关闭；确定失败后恢复适用操作。UNKNOWN 按[未知结果交互](../02-架构与设计/09-前端视觉与交互规范.md#4-浮层与反馈)保留核对与具体离开确认，不无限禁用关闭、导航或主动退出。
- H07 嵌套弹层：抽屉内选择器、提示和二次确认不被父层遮挡。
- H08 顶层 Esc：一次 Esc 仅关闭最上层，不同时关闭菜单、抽屉和导航。
- H09 焦点限制：Tab 在模态区域内循环，背景不响应点击或键盘操作。
- H10 焦点恢复：关闭回到触发按钮；触发对象已删除时回到合理位置。
- H11 滚动锁定：弹层打开后背景不滚动，关闭后恢复原滚动位置。
- H12 桌面弹层：弹层使用 Element Plus 的视口定位和焦点管理，不被局部容器裁剪；桌面键盘操作下输入和提交仍可访问。
- H13 确认文案：必要确认写清对象、动作和影响，按钮用具体动作；普通可恢复动作不叠无必要确认，补充详情在同框展开。
- H14 确认取消：取消不发送写请求，也不改变列表状态。
- H15 反馈去重：操作结果与读取失败统一使用页面顶部 Message，同一反馈只展示一次，不叠加页面或抽屉内提示；批次归属、去重后的对象动作、时长及关闭后恢复按[反馈规则](../02-架构与设计/09-前端视觉与交互规范.md#4-浮层与反馈)。
- H16 消息可阅读：悬停或聚焦暂停自动消失，可手动关闭。
- H17 错误归属：字段校验留在字段旁，表单提交和读取失败由 Message 承接并保留必要重试动作；静态说明和长期业务状态留在所属内容区，过期或换号结果不提示。
- H18 安全诊断：Message 简述，排查入口打开只读详情，不展示秘密。
- H19 Tooltip：键盘与鼠标均可访问；关键禁用原因不能只藏在 Tooltip 中。
- H20 回到顶部：只控制当前页面滚动区，不误滚动后台页面或编辑器。

## 10. 文件编辑器、上传与版本流程规则（I）

- I01 文件树识别：目录、文件、选中项、当前目录和文件路径清晰可辨。
- I02 文件树键盘：支持方向键展开/收起和移动、Enter 打开、F2 重命名、Delete 发起删除。
- I03 文件右键菜单：提供打开、新建、重命名、删除、复制路径、下载；按对象类型和只读状态决定可用项。
- I04 目录操作：目录重命名或删除通过当前文件集合处理，操作前校验全部目标，冲突时不做部分修改。
- I05 新建路径：显示目标目录，明确文件与目录模式；Enter 确认、Esc 取消。
- I06 路径校验：重名、非法路径、越界路径等使用现有包规则校验，错误就地显示。
- I07 空目录：弱化内部占位文件，向用户表达为空目录，保持实际包内容正确。
- I08 删除确认与撤销：目录删除展示影响文件数；保存或切换版本前允许撤销最近一次本地删除。
- I09 当前文件删除：删除后选中合理的相邻文件，或进入明确空态。
- I10 变更列表：展示新增、修改、删除及数量，点击可定位；已删除内容可查看基线。
- I11 文件内容状态：明确文本、二进制、只读和编辑器加载失败状态。
- I12 编辑器降级：高级编辑器不可用时保留基础编辑能力，并说明当前状态。
- I13 文件切换：切换文件不丢失当前草稿中的编辑内容，撤销/重做不能把另一文件正文写入当前文件；状态隔离按[编辑器工程规则](../../.agents/skills/nw-engineering/references/engineering-standards.md#前端状态与接口消费)执行。
- I14 编辑快捷键：保留撤销、重做、查找；Ctrl/Cmd+S 调用当前工作区保存。
- I15 保存反馈：显示保存中、已保存或失败，快捷键与按钮共享防重逻辑。
- I16 差异查看：可展开当前文件与基线差异，不撑破工作区；大内容采用受控滚动。
- I17 上传方式：普通文件和 ZIP 支持选择与拖放；目录导入使用目录选择入口。
- I18 已选摘要：展示文件名、数量、体积和目标目录，允许提交前移除。
- I19 上传校验：格式、数量和大小限制来自真实契约或现有配置；拒绝原因显示在上传区。
- I20 覆盖提示：替换当前文件、覆盖同名文件或导入整个包前明确影响。
- I21 导入状态：能获得真实进度时显示进度，否则显示处理中，不伪造百分比。
- I22 导入失败：保留原草稿及可恢复信息，明确失败后允许再次选择同一文件，不能仅依赖已选文件不变时不会触发的 `change`；重置选择器不丢弃已取得的文件。上传结果未知按原操作核对，不自动重传，也不表现为无说明的部分成功。
- I23 下载范围：明确下载当前文件、草稿包或发布版本包，文件名包含可识别对象和版本。
- I24 版本切换：显示草稿、发布、默认和只读标记；切换前检查未保存修改。
- I25 草稿续接：区分继续已有草稿与基于指定版本创建草稿，说明实际加载的草稿。
- I26 版本号来源：说明来自文件元数据、可编辑或固定的原因，冲突定位到对应字段。
- I27 校验绑定：结果绑定定义、草稿、修订和内容；内容变化后旧校验结果失效。
- I28 校验定位：显示问题总数、按文件分组，在树中标记并定位具体文件/行。
- I29 发布条件：可读地说明未保存、未校验、校验失败等禁用原因。
- I30 发布确认：展示目标版本、内容摘要和校验状态，按[版本生效说明](#101-版本生效说明)表达影响；成功后从服务端读取并展示实际发布结果。
- I31 设置默认：确认当前默认和目标版本，按[版本生效说明](#101-版本生效说明)说明采用范围；成功后同步版本列表。
- I32 冲突重新加载：明确本地修改影响；取消重新加载时保持编辑内容。

### 10.1 版本生效说明

保存草稿、发布版本、设置默认、更新绑定或挂载、启用及运行时采用是不同动作。确认、状态和成功提示依据所属领域的真实契约，说明本次改变的对象、影响范围和生效时机；接口完成发布或默认指针更新，不能单独作为所有消费者已升级的证据。

对固定版本绑定与已冻结执行，明确是否需要显式升级、重新发布消费者或开始新执行；对跟随默认的消费者，按实际解析时机说明何时采用。当前页面未取得采用范围或运行结果时，只陈述已确认的动作，不推断“全部已更新”或“新执行立即生效”。Skill 发布提示应区分默认版本、Agent 实际挂载版本与 Run 冻结版本，不把设置默认写成已更新固定挂载。相关规则解释已有领域契约，不由前端另定义版本切换行为。

## 11. 桌面窗口、权限与异常规则（J）

- J01 桌面工作区：在批准的桌面浏览器和窗口范围内，列表、表单、编辑器和操作区合理使用可用空间。
- J02 窗口变化：桌面窗口大小或缩放变化后，核心操作、焦点和滚动仍可访问；模板响应式能力不扩展为手机支持承诺。
- J03 模板响应式：若 后台公共资源 模板提供响应式降级，保持上游行为，不新增手机布局、触屏手势或专项验收要求。
- J04 页面缩放：文字缩放与内容重排按[视觉规范](../02-架构与设计/09-前端视觉与交互规范.md#31-可访问性尺度)执行，不能用桌面优先范围豁免；核心操作与内容保持可访问。
- J05 普通交互替代：菜单和提示复用 Element Plus 的键盘交互；拖动提供[非拖动指针替代](../../.agents/skills/nw-ui-ux/references/responsive-layout.md#图标触屏与焦点)，不以仅有键盘操作代替点击路径，不自建平行菜单交互。
- J06 浮层重算：桌面窗口变化后重新计算弹层、表格和编辑器可用区域，不遗留错误遮罩。
- J07 键盘可用性：焦点顺序符合视觉顺序，图标按钮具有名称；焦点遮挡、弹层返回与删除后的去向按 [UI 焦点规则](../../.agents/skills/nw-ui-ux/SKILL.md#弹层菜单与输入)执行。
- J08 可访问性尺度：正文、辅助文字、禁用说明、控件图形及焦点指示、点击区域和文字适配按[视觉规范](../02-架构与设计/09-前端视觉与交互规范.md#31-可访问性尺度)执行。
- J09 长内容与极值：覆盖超长名称、长 ID、空字段、大金额和大量条目。
- J10 慢请求与断网：加载状态可辨认，失败可重试，不能把失败误报为成功或无数据。
- J11 重试边界：GET可重读；写结果未确认先核对原操作，禁止盲目重发。
- J12 权限一致：按动作实际调用的接口及其资源范围绑定既有权限，不能仅凭页面名称或相邻按钮推定权限码；按钮、菜单和快捷键使用同一授权结果。创建定义、编辑草稿、校验和发布分别核对；一次操作必须串行完成多个受保护步骤时，检查其必要组合权限，独立的可选动作不并入前置条件。缺少权限时按既有可见/禁用策略说明原因；前端显示控制不能替代后端授权。受影响验收同时覆盖有权成功与缺少必要权限的拒绝，不能只用管理员账号证明权限正确。
- J13 外部状态变化：对象被他人删除、状态改变或修订冲突时说明原因并允许刷新。
- J14 后台轮询：非活动页面和浏览器不可见时暂停无必要轮询，恢复可见时更新。
- J15 本地存储受限：存储不可用或损坏时仍能使用系统，只降低偏好恢复能力。
- J16 业务缺口呈现：没有现有业务能力的功能不放置无效按钮或成功假提示。

## 12. 平台页面职责目标（P）

本节只定义页面职责与应提供的目标能力；页面详细交互必须同时满足第 2 至第 11 节，不记录实现状态。

- P01 工作台：展示机构数、模板数、待审核数和依赖健康统计；统计跳转对应页面；待审核跳转携带条件；快捷入口与菜单一致；单项失败不抹掉其他数据；提供刷新及最近更新时间；提供加载与局部失败提示。
- P02 系统状态：展示整体健康结果、健康/异常数量和依赖列表；异常项优先；安全诊断详情可展开；区分检查失败与依赖异常；显示刷新状态及最近成功检查时间。
- P03 机构管理：以表格展示机构名称、标识、套餐、状态和创建时间；支持关键词和状态查询、开通机构、字段校验、启停确认、行菜单、创建后刷新和返回列表上下文恢复。
- P04 机构详情：展示对象摘要；提供概览/成员页签及地址恢复；分组编辑基本信息、套餐、部署和配额；提供启停、成员角色/状态筛选、服务端分页、成员增改停用和重置密码；支持局部错误重试和抽屉未保存保护。
- P05 模型费用账单：按机构和北京时间月份只读查询原模型用量与冻结成本，提供调用次数、Token、已计算费用、总费用缺口、服务端分页及原价格依据；区分筛选未提交、加载、空态、失败和权限变化，不提供独立销售价格或账单写操作。
- P06 运营管理：提供审计日志/账单状态处理页签；支持动作、机构和最近条数查询、重置、匹配总数与返回范围、长日志详情、资源标识复制、扫描前影响确认、扫描结果分类、完成时间和失败重试；没有真实能力的分页、导出不显示。
- P07 工作流审核：默认进入待审核；提供全部/待审核/通过/驳回页签及地址恢复；展示工作流与提交信息；通过需确认，驳回支持理由字段；按行反馈结果并刷新队列；明确固定返回范围。
- P08 智能体模板列表：支持状态与分类筛选；展示名称、模板标识、版本、安装量和更新时间；支持分页、页大小、新建、草稿编辑/发布/删除、已发布版本修订/废弃、废弃版本归档及行菜单；确认中展示名称与版本，操作后保留原列表。
- P09 模板新建与详情：分组展示基本信息、执行配置、能力资源和协作角色；展示名称与版本摘要、模型与运行预算、能力挂载、机构资源槽位和动态角色；支持保存草稿、校验、问题摘要与定位、只读版本修订、发布确认和未保存保护；文案进入国际化资源。
- P10 统一模型管理及维护：提供模型列表、名称/类型/提供方/状态筛选、凭据配置标识和独立维护页；支持提供方/服务/协议级联、模型发现、LLM/Embedding/Rerank 动态参数、密钥留空语义、模型测试与延迟结果、版本历史、回滚确认、修订冲突和返回列表状态恢复。
- P11 系统智能体列表：支持名称/标识搜索、状态和执行模式筛选、完整集合分页；展示用途、模式和版本；提供创建抽屉、标识与名称校验、维护入口、行菜单以及创建和维护后的刷新。
- P12 系统智能体详情：提供草稿配置/已发布版本/调试与运行记录；分组展示模型、提示词、执行限制和 Skill/Tool 挂载；支持未保存保护、保存、发布、启停、归档、调试来源选择、输入校验、运行状态与详情、自动刷新指示、不可见时暂停轮询及修订冲突提示。
- P13 平台工具部署：支持名称、环境和启用状态筛选；展示工具、版本、提供方引用和环境标记；支持创建/编辑、选项加载失败重试、生产变更确认、字段校验、修订冲突和按行反馈。
- P14 系统配置：提供设置组导航并将当前组写入地址；按 schema 渲染字段、标签、帮助、单位和校验；展示修订与未保存提示；支持撤销编辑、组切换保护、固定保存栏、密钥留空语义、历史加载/空态/失败、历史内容查看复制及回滚确认。
- P15 能力目录及详情：提供定义列表、类型/状态筛选和重置；独立详情展示基本信息、版本列表和当前版本；支持定义创建、草稿新建/复制、JSON 校验与定位、ZIP/目录导入、版本绑定校验结果、发布条件说明、发布确认、默认版本状态及带上下文进入技能工作区。
- P16 技能维护列表：以表格展示名称、能力标识、状态和描述；名称/标识搜索和完整集合分页按[P16 控件合同](后台控件/P16-技能维护列表.md)区分目标与当前实现。机构与平台的新建表单校验 metadata，以一次命令原子创建定义和空草稿，任一步失败整体回滚；双创建权限缺一不可，平台 scope 固定且不接受机构覆盖。成功保存原回执并进入对应草稿，导航失败继续使用原入口；UNKNOWN 只读核对原选择，不重发 POST，不以同标识、缺失结果或冲突冒充原回执。ZIP 导入独立保留。
- P17 技能维护工作区：提供文件树及按 Element Plus 标准装配的菜单、文件/目录创建重命名删除、变更列表、文本编辑与二进制下载、差异查看、导入替换、当前文件/整包下载、版本浏览、草稿续接、版本号联动、配置与依赖、保存快捷键、校验定位、发布、默认版本、冲突恢复和只读模式。
- P18 登录页：提供用户名/密码校验、自动填充、密码显隐、输入法与 Enter 提交、提交防重、页面顶部 Message 失败提示、明暗主题、返回登录前目标和非法跳转参数处理；MFA 阶段、身份重建及迟到认证反馈按[认证状态归属](../../.agents/skills/nw-engineering/references/engineering-standards.md#前端状态与接口消费)处理。
- P19 403：说明权限不足；提供返回上一有效页、按实际权限进入工作台和切换账号；退出当前身份后再登录以避免跳转循环；适配 后台公共资源 主题和桌面键盘交互。
- P20 404：说明地址无效；支持长路径展示、返回上一页、工作台入口、未登录时登录入口；不影响其他已打开标签；适配 后台公共资源 主题和桌面键盘交互。

## 13. 后端协作与接口契约规则

平台直管接入使用既有平台端和机构端，控件合同见[逐控件规格 P22–P25](06-后台逐控件规格.md#p22-平台管理身份)。

- P22 平台管理身份：按当前动作展示管理机器目录和创建、轮换、撤销；明确 scope 与 Tenant/定义/namespace 目标；写入携带稳定幂等键和适用 CAS，秘密仅首次交付，结果未知先读取安全目录核对。
- P23 机构接入与执行凭证：外部 namespace＋机构标识开通或明确关联已有 Tenant；开通与签发分开；固定 Tenant/integration 的执行凭证单独签发、轮换、撤销，按各自动作和对象范围过滤。
- P24 公共定义授权与机构实例：平台明确直授目标机构；部署显式选择 definition/grant 并配置本地绑定，绑定修改使用 deployment_revision CAS；机构不能因此维护源定义或独立复制受控定义。
- P25 平台与机构用量：人员视图与机构 ServicePrincipal 入口各自认证；先按当前范围过滤再分页，游标按原样续读，授权或筛选变化需显式从起点重建；请求与实际调用分开，未知计量不补零，金额按币种使用精确分字符串。

SaaS 基础底座新增 P26–P32 双宿主页面：组织与权限、账号安全、菜单字典与配置、公告与通知、公共文件、导入导出与管理任务、日志与运维。页面职责与稳定对象编号见[逐控件规格 P26–P32](06-后台逐控件规格.md#p26p32-saas-基础底座)，领域契约见[SaaS 基础底座设计](../02-架构与设计/19-SaaS基础底座设计.md)；这些入口沿用 A–J 规则，不以菜单隐藏代替接口、数据范围或对象授权。

**K01** UI 目标需要完整列表、服务端分页、远程搜索、独立详情、批量操作、导出或字段级错误时，可以新增或调整后端接口、应用服务、数据查询和响应 DTO；前后端必须同步更新调用方、类型、接口文档和必要测试。

**K02** 列表接口必须返回真实总数、当前页信息和实际返回范围；服务端排序、筛选和分页不得伪造全量结果；后端无法提供全量能力时，前端必须按受限范围表达。

**K03** 详情接口必须按对象身份和权限返回完整详情；列表摘要不得要求前端逐行发起额外详情请求形成 N+1；对象不存在、无权限、状态冲突和修订冲突必须使用可识别的稳定错误语义。

**K04** 写接口必须保持权限、租户隔离、幂等、防重复提交、并发控制、事务一致性、审计和错误原因链；前端的确认、loading 或按钮禁用不能替代后端约束。

**K05** 金额、用量、数量、版本号和结构化配置必须保持契约规定的精度与空值语义；前端不得通过浮点转换、伪造掩码或默认值改变真实含义。

**K06** 需要驳回理由、调整理由或其他业务说明时，前后端共同定义字段、长度、必填条件、保存事实、权限和审计语义；没有对应后端能力时前端不得伪造成功结果。

**K07** 后端错误响应应区分字段错误、表单错误、对象不存在、权限拒绝、状态冲突、修订冲突和系统故障；原始技术异常不直接作为用户主文案。

**K08** 批量操作和导出只有在接口、权限、范围、幂等、失败结果和审计语义完整时提供；部分成功必须返回逐对象结果或明确的整体失败，不以单条成功替代整体结果。

批量结果展示成功、失败与未知的实际范围，保留失败对象及处理入口；不得因部分失败自动重放已成功或结果未知的对象。选择与清空行为仍按 F28/F29，不引入跨页选择能力。

**K09** 接口变更时同步检查直接消费者、OpenAPI 描述、前端类型、权限入口、数据清理与保留规则和真实接口验证；不以旧接口兼容为理由保留与当前目标架构冲突的实现。
