# 租约与 Fencing：接管任务时怎样挡住旧 worker

前置阅读：[19 课](19-持久化状态机与事实源设计.md)、[20 课](20-幂等外部副作用与未知结果.md)、[21 课](21-Inbox-Outbox与可靠事件交付.md)、[24 课](24-运行中纠正取消与限流重试.md)

运行研究助手的 worker A 停顿了，调度器让 worker B 接管同一 Run。B 已经完成资料汇总，A 却恢复过来，准备把较旧结果写回。即便任何时刻只有一个租约看起来有效，两个进程仍可能同时活着。

租约解决“当前应由谁推进”，Fencing 解决“接收写入的一方怎样识别过期持有者”。两者配合能保护参与检查的存储，却不能自动撤回已经发向外部系统的请求。

## 过期是资格变化，不是进程死亡

租约保存持有者、到期时间和递增的代际 token。worker 在期限内续约，续约失败后停止新工作。调度器可以在租约过期后授予新的持有者，但不能假设旧进程已经退出。

A 的 token 为 41，B 接管后拿到 42。A 恢复并提交结果时，存储侧检查 token 仍为当前代际，发现 41 过期就拒绝。只有 worker 自己检查“我的租约还有效”不够，因为检查后它还可能停顿，醒来再写。

教学伪代码可以表达这种条件提交：

```text
commit_result(run_id, expected_version, fencing_token, result):
    update only if
        run.version == expected_version
        and run.current_fencing_token == fencing_token
        and run.state permits this transition
    if no row changed:
        reload committed state
        discard stale write intent
```

version 处理同一代际内的状态竞争，token 处理持有者代际变化。具体数据库实现可以不同，但检查与写入需要形成原子条件，不能先查后无条件更新。

## 谁不检查 token，谁就不受它保护

假设 A 在暂停前已经发出发布 D1 的 HTTP 请求，对方完全不认识 fencing token。B 获得 42 后，无法靠本地租约阻止 A 的请求在远端生效。若 B 直接再发一次，仍可能重复发布。

因此接管时要读取未收敛的 Action 与 Attempt。只读调用可按策略恢复；外部写入若结果未知，应使用稳定幂等键查询或重试，或者进入核对流程。Fencing 与幂等保护的是不同边界，不能相互替代。

有些外部存储支持条件版本写入，可以把 token 或版本纳入检查；有些只支持请求去重；还有些两者都不支持。系统应按真实能力选择恢复策略，并向用户保留无法自动消除的未知状态。

## 续约和时间需要可靠依据

租约的发放、到期与续约最好使用统一的权威时间判断，避免多台机器本地时钟漂移导致错误接管。执行器测量本地耗时可使用单调时钟，但它不能替代分布式存储中的租约到期规则。

租约太短会在正常暂停或网络抖动时频繁接管，太长会延迟故障恢复。不存在适合所有任务的固定秒数。应结合任务时长、续约延迟、停顿分布和故障目标选择，再用故障注入检查边界。

长调用期间续约失败，worker 应停止派发新动作，并把返回结果交给有代际检查的提交入口。它不应为“保住工作成果”绕开条件写入。结果可能需要由新持有者重新核对，但状态不能因此被旧持有者覆盖。

## 接管后不必从头让模型再想一次

B 接手时应读取当前 Run、冻结请求、已提交 Observation、等待对象和未决效果。已经完成的只读结果可以复用；已经确定的动作也不必让模型重新生成一个相似动作。

这不仅降低重复工作，也避免语义漂移。A 决定发布 D1，B 重新让模型规划后可能生成 D2；如果把两者视为同一次重试，就破坏了稳定动作身份。接管恢复的是已记录的事实，再在新的决策点继续。

对单进程、无接管要求的教学工具，不必一开始引入分布式租约。需要多个 worker 竞争任务或进程故障后自动恢复时，这套边界才成为必要工程。

## 用两个 worker 检验写入资格

练习：A 持有 41，发布请求已发送但响应丢失；B 获得 42；A 返回并提交“发布成功”；B 准备重发。写出每一步允许的动作。

预期结果：A 的过期状态写入被拒绝，但这并不能证明它的远端发布未发生；B 先核对原 Action 的结果，不能仅因接管成功就盲重发。若对方支持稳定幂等键，可以按其契约查询或重试同一内容；否则保留未知并寻求核对。正确答案同时保护本地写权和外部效果边界。
