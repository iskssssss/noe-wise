# ADR-010：外部调用弹性策略

> **状态**：Accepted · **日期**：2026-08-05 · **Owner**：架构

## 当前适用边界

下文的接入状态、阈值和 LLM 确定性回退是 2026-08-05 的决策快照。Runtime 的自动重试、未知结果与副作用边界由 [Harness 03](../../harness-design/03-核心对象模型与状态机.md#93-内部调度与外部副作用边界) 接管，不能据此恢复旧 Planner 路径或对结果未知的外部副作用统一重试三次；旧路径替换见 [Harness 06](../../harness-design/06-MVP-0技术底座实施方案.md)。

## 背景

LLM、HTTP 连接器与 Elasticsearch 等外部依赖可能超时或故障；
缺少超时、退避重试与熔断会让请求堆积并放大故障。

## 决策

- 新增 `Resilience` 组件，统一提供“超时（调用方）→ 带指数退避的重试 → 熔断”三件套。
- 每个命名依赖独立熔断器：连续 3 次失败打开，10 秒后进入半开探测，
  探测成功即恢复关闭。
- 已接入：LLM 调用、HTTP 连接器、Elasticsearch bulk/search。
- 熔断打开时快速失败：LLM 走确定性回退，连接器返回错误映射，ES 回退 pgvector/关键词。

## 权衡

- 初始仅覆盖调用频次最高的三类外部依赖，后续按业务需要扩展；
- 重试会放大瞬时失败，故限制为 3 次尝试并以指数退避错峰。
