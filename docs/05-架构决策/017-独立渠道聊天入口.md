# ADR-017：独立渠道聊天入口

- 状态：Accepted
- 日期：2026-09-21

## 背景

纯聊天使用者需要在机构管理后台之外访问渠道智能体。管理端身份不能成为聊天客户端的隐含依赖，浏览器也不能内置供所有使用者共享的签名密钥。

## 决策

独立 `frontend-chat` 静态应用由每位使用者配置渠道令牌或 OpenAPI 渠道 API Key 与 HMAC Secret。凭证保存在当前标签页 sessionStorage，刷新后重新验证并恢复身份，关闭标签页或主动断开后清除；访问者 client_ref 和服务端签发的 identity_token 按服务地址与渠道保存在 localStorage，主题偏好独立保存；主动断开不清除访问者记录，服务端确认身份失效时移除。浏览器存储不可用时不保证持久化；不增加签名代理。

智能体发现和会话访问均由宿主服务校验当前渠道绑定及发布状态。界面隐藏不承担授权职责。渠道解绑后，后续历史读取、回放和发送请求拒绝访问。

本机 UUID 与昵称通过机构、渠道和本机标识的唯一映射登记终端用户，数据库事务及约束保证并发幂等。该映射用于恢复聊天身份，不构成独立登录，权限仍来自渠道凭证。此变更属于机构宿主入口，不改变 Runtime 身份或执行契约。

接口定义见[接口与事件契约](../02-架构与设计/04-接口与事件契约.md)，开发与部署见[聊天前端说明](../../frontend-chat/README.md)。

## 验证要求与限制

后端验证真实渠道令牌、HMAC、绑定范围及解绑拒绝，数据库验证身份登记唯一性、事务与租户隔离。前端验证精确签名字节、凭证生命周期、流重连去重、会话切换与历史恢复。模拟接口和静态构建不能证明真实模型端到端成功，目标部署需单独验收。操作说明及当前客户端行为见[聊天端说明](../../frontend-chat/README.md)。
