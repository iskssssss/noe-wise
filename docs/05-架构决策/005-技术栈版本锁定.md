## 决策（按 2026-08 修订）

> 2026-08-05 修订：后端已切换为 Java（见 [ADR-007](007-Java后端技术栈.md)），
> 本文保留技术选型决策；具体依赖版本以 `backend-java/gradle/libs.versions.toml`、各模块构建文件及前端锁文件为准，不能仅凭表格判断部署或验收状态。

| 领域 | 锁定选择 | 说明 |
| :--- | :--- | :--- |
| 前端框架 | **Vue 3 + TypeScript + Vite** | 目录约定 `frontend-admin/src/views/` + `frontend-admin/src/router/` |
| UI | Element Plus + 项目共享组件与视觉规范 | 机构后台和平台后台共用 `frontend-shared` |
| 流程编辑 | 项目工作流画布 | 可视化构建器；范围与限制见[工作流规范](../03-规范与术语/01-工作流规范.md) |
| AI 编排 | 应用内 Agent Runtime + Workflow Runtime | Runtime 边界以 [Harness Design](../../harness-design/README.md) 为准；模型调用由 Agent Runtime model adapter 与应用内 Provider 按所选协议接入 |
| LLM 适配 | **Agent Runtime model adapter + 应用内 Provider** | 按提供方协议装配；OpenAI 兼容 Chat Completions 与 Responses 适配使用 OpenAI Java SDK，具体支持范围以[模型适配器](../../backend-java/agent-runtime-adapter-model/src/main/java/com/skillforge/runtime/adapter/model/)及配置为准 |
| Web | Java 21 + Spring Boot 3 + Spring WebMVC + MyBatis-Plus | 多模块 `backend-java/` |
| 数据库 | PostgreSQL 16 + pgvector | 产品化引入 Elasticsearch |
| 缓存与调度 | Redis 7.x + Spring 调度及持久任务状态 | 各任务的存储、派发与恢复边界由所属实现定义 |
| 身份 | **应用内 JWT + RBAC** | 见 ADR-001 |
| 密钥 | **环境 KEK + 租户 DEK 信封加密** | 不强制 Vault |
| API 网关能力 | **Spring Cloud Gateway** | 路由并透传 SSE/WebSocket，可选 Nacos 与 Sentinel；身份、权限和业务幂等由所属服务执行 |
| 可观测 | 结构化日志 + Prometheus 指标 + 可选 OTLP | Alloy 可选，非强制 |
| 文件存储 | 当前产物使用受控本地文件存储 | 部署路径和持久化要求见[代码执行与产物交付](../02-架构与设计/12-代码执行沙箱与产物交付.md) |

### 分阶段依赖

| 阶段 | 引入 |
| :--- | :--- |
| MVP-0 | PG+pgvector+Redis+Spring Boot、Stateful Agent Runtime、Multi-Execution Session Runtime、内置身份和 Mock Connector |
| P1 | 渠道与 Runtime 产品化、增强记忆、任务运营、第三方回环；Elasticsearch 按已确认需求引入 |
| P2 | 分布式执行韧性、任意节点续跑和 Agent 委派 |
| P3 | 动态插件生态、完整沙箱和供应链强化；联邦学习另行设计 |

## 后果

- README / 部署指南与 `backend-java` 各模块 `build.gradle.kts` / 两个前端
  `package.json` 对齐。
- 部署 compose（`deploy/docker-compose.java.yml`）包含 PG、Redis、Nacos 和 Elasticsearch；
  默认 `make up` 仅启动 PG + Redis + Nacos，需要 Elasticsearch 时使用启动全部服务的既有入口或显式启动该服务；移除 Keycloak/Kong/Vault 必选服务。
- 代码执行与沙箱的当前装配、部署前置条件和限制见[代码执行与产物交付](../02-架构与设计/12-代码执行沙箱与产物交付.md)；能力启用不等于所有场景已验收。

## 不做的事

- 不把商业 SaaS（Auth0 等）作为默认路径。
- 不宣称已实现 gVisor/Firecracker Code Node 沙箱。
