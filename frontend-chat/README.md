# 灵知 · 独立会话端

独立会话端是灵知面向最终用户的交互入口。用户在持续会话中描述目标、附上资料和图片、查看助手回复与执行进度，并在需要时补充信息、确认操作或使用正式成果。专业协作与成果面板消费后端公开投影，Agent 的判断、能力授权和任务状态由服务端运行时维护。产品角色与完整旅程见[产品概述](../docs/01-产品与需求/02-产品概述.md)和[产品需求文档](../docs/01-产品与需求/01-PRD.md)。

会话应用独立使用 Vue 3、Lucide、marked 与 DOMPurify。它不引用机构端、平台端、后台公共层、Element Plus 或仓库后台构建插件；`src/ui/controls/` 持有会话端自己的表单、选择器、抽屉、上传、折叠、表格和反馈控件。抽屉和确认框通过原生 dialog 管理模态焦点，选择器支持键盘导航与筛选。

`src/style.css` 集中定义明暗主题、8pt 间距、圆角、阴影与动效令牌，默认深色并恢复已保存的主题。桌面会话和成果采用 12 列栅格，窄屏面板使用模态布局；键盘焦点、触屏点击区域和减少动态效果偏好由同一套样式管理。

## 启动与验证

服务启动遵循仓库[开发与部署指南](../docs/04-指南与运维/01-开发与部署指南.md)的本地启动节。独立模块命令：

```sh
corepack pnpm --filter frontend-chat dev
corepack pnpm --filter frontend-chat test
corepack pnpm --filter frontend-chat lint
corepack pnpm --filter frontend-chat format:check
corepack pnpm --filter frontend-chat build
```

ESLint 使用会话端自己的 Vue 3 essential 与 TypeScript recommended flat config，检查源码、测试和本地脚本。Prettier 单独负责格式化，`format` 可写入格式修正；ESLint 最后加载 `eslint-config-prettier`，避免重复处理格式规则。

开发端口默认 3200，`/api` 代理至 `http://localhost:8000`，可通过 Vite 的 `--port` 指定实际端口。构建输出为 `dist/`，静态部署示例见 `nginx.conf.example`。跨域服务须显式允许页面来源与渠道认证请求头；生产使用 HTTPS。

## 模块与交互

- `protocol.ts` 声明会话端实际使用的公开 DTO。
- `client.ts` 持有 HTTP envelope、渠道令牌/HMAC 和 SSE 传输。POST 不自动重试；GET 观察使用 Last-Event-ID 有界重连。游标过期后以权威历史恢复；历史返回精确的成果发布等待状态时，沿用首次读取的最多五次、可取消等待，成功后才采用新游标，普通故障保持原错误。
- `projection.ts` 按公开消息版本、过程更新序号与 Session 序号合并投影。
- `session.ts` 持有连接身份、会话选择、输入冻结、附件、历史和取消状态。
- `ui/` 为会话自身的补参、团队、成果、浏览器设备、目标与协作面板；不是后台公共资源。

连接时验证渠道并登记访问者。凭证仅保存在当前标签页的 sessionStorage，关闭标签页或主动断开连接后清除。随机 client_ref 按服务地址与已验证渠道保存在 localStorage，昵称不是认证凭据。重新加载同一标签页会重新验证连接，再恢复仍有权限访问的目标及会话。主题选择独立存储。

发送先创建稳定 Session，再提交一次带 client_message_id 的请求。网络结果未知时保留完整请求；“重试原请求”复用身份、正文、附件与引用。切换目标或会话只释放本地观察，不取消后端运行。停止运行调用取消接口并持续核验真正终态；等待用户输入不等于取消完成。预算或策略使运行进入 `terminated` 时显示“已终止”，停止取消状态轮询并恢复消息输入，不自动重新提交；结果未知仍保留原有状态与处理边界。

消息、图片与 Markdown 从公开数据渲染。历史分页与在线事件按版本合并，引用保留公开选择器。工具补参和 Plan 评审提交原等待身份。目标、运行补充、团队及协作控制均调用现有真实接口；命令目录支持上下键、Enter/Tab 选择与 Escape 关闭，只填写草稿，不直接执行。团队与工具使用互斥抽屉，提交期间禁止关闭，未提交修改离开前确认；切换会话同样经过抽屉保护。上传控件将一次选择的多个文件合并，再交给独立签名客户端上传。

长文本粘贴按实际选区合入后的正文判断用途：`/goal` 等本地控制命令保留原生文本粘贴，不转换为只供普通消息消费的附件。目标正文完整交给现有命令入口，格式和长度限制在发送时校验；普通长消息继续按现有规则暂存文本附件，确认发送前不上传。目标命令反馈只显示当前状态与轮数，完整正文在“会话工具”的目标页查看，避免长目标占满顶部反馈区域。

运行中可以为下一条消息选择或粘贴资料与图片，已确认上传的项目保留在当前草稿；上传只准备资料，不提交新消息，也不改变当前执行已冻结的附件身份。当前运行结束后，用户明确发送才采用下一条草稿中的资料。类型、大小和会话容量限制、输入模式及切换会话后的迟到回执处理继续适用。

成果按需读取，下载和预览每次取得受控票据，预览 iframe 使用 sandbox。恢复成果版本只加入下一条消息的引用，由用户发送。浏览器配对、默认设备、改名、撤销与取消使用当前访问者的真实接口。

接口事实源为后端公开 DTO 和[接口与事件契约](../docs/02-架构与设计/04-接口与事件契约.md)。本模块测试覆盖签名字节、SSE 分块、身份切换、输入幂等、排队恢复和工具补参；真实模型、真实浏览器设备及外部工具的完整验收需在对应环境另行执行。
